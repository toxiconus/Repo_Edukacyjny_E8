# 0. Cel i kryterium gotowości

Uczennica:
- zapisuje trzy poziomy równania (cząsteczkowe → pełne jonowe → skrócone),
- korzysta z tabeli rozpuszczalności lub reguł,
- przewiduje powstanie osadu i jego barwę,
- projektuje sposób otrzymania soli i wykrycia jonów,
- unika typowych błędów (jony widzów, brak ↓, mylenie barw).

# 1. Trzy poziomy zapisu — algorytm

1. **Cząsteczkowe** — zbilansowane, wzory sumaryczne.
2. **Jonowe pełne** — mocne elektrolity zapisujemy jako jony (sole rozpuszczalne, mocne kwasy, mocne zasady).  
   Osady, gazy, słabe elektrolity (H₂O, słabe kwasy) zostawiamy w formie cząsteczkowej.
3. **Jonowe skrócone** — skreślamy jony widzów (te same po obu stronach).

**Przykład zobojętniania:**
NaOH + HCl → NaCl + H₂O  
Na⁺ + OH⁻ + H⁺ + Cl⁻ → Na⁺ + Cl⁻ + H₂O  
**OH⁻ + H⁺ → H₂O**

**Przykład strącania:**
AgNO₃ + NaCl → AgCl↓ + NaNO₃  
Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl↓ + Na⁺ + NO₃⁻  
**Ag⁺ + Cl⁻ → AgCl↓**

# 2. Tabela rozpuszczalności — reguły do opanowania na pamięć

| Reguła | Wyjątki |
|--------|---------|
| Wszystkie azotany(V) — R | — |
| Wszystkie sole Na⁺, K⁺, NH₄⁺ — R | — |
| Większość chlorków — R | AgCl, PbCl₂, Hg₂Cl₂ — N |
| Większość siarczanów(VI) — R | BaSO₄, PbSO₄, CaSO₄, SrSO₄ — N/T |
| Wodorotlenki metali I i II grupy (oprócz Be, Mg) — R | reszta zwykle N |
| Węglany, fosforany, siarczki — zwykle N | sole metali I grupy i amonu — R |

Oznaczenia: **R** = dobrze rozpuszczalna, **N** = nierozpuszczalna (osad ↓), **T** = trudno rozpuszczalna.

# 3. Charakterystyczne osady i barwy (obowiązkowe)

| Osad | Barwa | Reakcja skrócona | Uwagi |
|------|-------|------------------|-------|
| AgCl | biały serowaty | Ag⁺ + Cl⁻ → AgCl↓ | rozpuszcza się w NH₃aq |
| AgBr | żółtawobiały | Ag⁺ + Br⁻ | |
| AgI | żółty | Ag⁺ + I⁻ | |
| BaSO₄ | biały | Ba²⁺ + SO₄²⁻ → BaSO₄↓ | nierozpuszczalny w kwasach |
| CaCO₃ | biały | Ca²⁺ + CO₃²⁻ | |
| Cu(OH)₂ | niebieski | Cu²⁺ + 2OH⁻ | |
| Fe(OH)₂ | brudnozielony | Fe²⁺ + 2OH⁻ | utlenia się na powietrzu |
| Fe(OH)₃ | brunatny/rdzawy | Fe³⁺ + 3OH⁻ | |
| PbI₂ | żółty | Pb²⁺ + 2I⁻ | |

# 4. Otrzymywanie soli — metody

1. **sól + kwas** (mocniejszy wypiera słabszy/lotny)  
   Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑  
   Jonowo: CO₃²⁻ + 2H⁺ → H₂O + CO₂↑

2. **sól + zasada**  
   CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄

3. **sól + sól** (podwójna wymiana — gdy powstaje osad, gaz lub słaby elektrolit)  
   AgNO₃ + NaCl → AgCl↓ + NaNO₃

4. **metal + sól** (wypieranie — patrz X04)

5. **kwas + zasada** (zobojętnianie)

# 5. Wykrywanie jonów — reakcje charakterystyczne

| Jon | Odczynnik | Obserwacja | Równanie skrócone |
|-----|-----------|------------|-------------------|
| Cl⁻ | AgNO₃ | biały osad (rozp. w NH₃aq) | Ag⁺ + Cl⁻ → AgCl↓ |
| SO₄²⁻ | BaCl₂ / Ba(NO₃)₂ | biały osad nierozp. w kwasach | Ba²⁺ + SO₄²⁻ → BaSO₄↓ |
| CO₃²⁻ | kwas + woda wapienna | gaz + zmętnienie | CO₃²⁻ + 2H⁺ → CO₂ + H₂O |
| Cu²⁺ | NaOH | niebieski osad | Cu²⁺ + 2OH⁻ → Cu(OH)₂↓ |
| Fe³⁺ | NaOH | brunatny osad | Fe³⁺ + 3OH⁻ → Fe(OH)₃↓ |
| Fe²⁺ | NaOH | brudnozielony osad | Fe²⁺ + 2OH⁻ → Fe(OH)₂↓ |

# 6. Zadania z pełnymi rozwiązaniami

**Zadanie 1**  
Zapisz równania cząsteczkowe, pełne jonowe i skrócone:  
a) KOH + H₂SO₄  
b) BaCl₂ + Na₂SO₄

**Rozwiązanie a):**  
2KOH + H₂SO₄ → K₂SO₄ + 2H₂O  
2K⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → 2K⁺ + SO₄²⁻ + 2H₂O  
2OH⁻ + 2H⁺ → 2H₂O  (lub OH⁻ + H⁺ → H₂O)

**Rozwiązanie b):**  
BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl  
Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻  
Ba²⁺ + SO₄²⁻ → BaSO₄↓

**Zadanie 2**  
Które pary dadzą osad? Zapisz równania skrócone.  
a) NaCl + AgNO₃  
b) KNO₃ + Na₂SO₄  
c) CaCl₂ + Na₂CO₃  
d) CuSO₄ + NaOH

**Rozwiązanie:**  
a) Ag⁺ + Cl⁻ → AgCl↓  
b) brak (wszystkie sole rozpuszczalne)  
c) Ca²⁺ + CO₃²⁻ → CaCO₃↓  
d) Cu²⁺ + 2OH⁻ → Cu(OH)₂↓

**Zadanie 3**  
Zaprojektuj sposób otrzymania czystego osadu Cu(OH)₂. Podaj odczynniki i równanie.

**Rozwiązanie:**  
Odczynniki: roztwór CuSO₄ i roztwór NaOH (lub KOH).  
CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄  
Osad odfiltrować i przemyć.

# 7. Najczęstsze błędy

- Pisanie jonów widzów w równaniu skróconym.
- Brak strzałki ↓ przy osadzie.
- Mylenie barw Fe(OH)₂ (zielony) i Fe(OH)₃ (brunatny).
- Stosowanie tabeli „na pamięć” zamiast reguł + sprawdzenie.

# 8. Mini-test

1. Zapisz skrócone jonowe: AgNO₃ + KCl  
2. Jaka barwa osadu Cu(OH)₂?  
3. Czy powstanie osad po zmieszaniu NaNO₃ + KCl?  
4. Jak wykryć jon SO₄²⁻?  
5. Zapisz skrócone: Ba(OH)₂ + H₂SO₄

**Klucz:** 1. Ag⁺ + Cl⁻ → AgCl↓; 2. niebieski; 3. nie; 4. Ba²⁺ (biały osad); 5. Ba²⁺ + SO₄²⁻ → BaSO₄↓ (oraz H⁺ + OH⁻ → H₂O).
