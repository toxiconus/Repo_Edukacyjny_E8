# Cel lekcji
Uczeń potrafi zapisać równanie cząsteczkowe, pełne jonowe i skrócone jonowe reakcji zobojętniania i strącania. Potrafi korzystać z tabeli rozpuszczalności, przewidzieć powstanie osadu i barwę charakterystycznych osadów. Potrafi zaprojektować sposób otrzymania soli i wykrycia wybranych jonów.

# Wymagania wstępne
- dysocjacja elektrolityczna kwasów, zasad i soli
- zapis wzorów soli i wodorotlenków
- bilansowanie równań
- pojęcie osadu

# 1 | Od równania cząsteczkowego do skróconego jonowego

**Kolejność zapisu:**
1. Równanie cząsteczkowe (z bilansem)
2. Równanie jonowe pełne (wszystkie mocne elektrolity jako jony)
3. Równanie jonowe skrócone (skreślamy jony widzów)

Przykład zobojętniania:
NaOH + HCl → NaCl + H₂O  
Na⁺ + OH⁻ + H⁺ + Cl⁻ → Na⁺ + Cl⁻ + H₂O  
**OH⁻ + H⁺ → H₂O**

Przykład strącania:
AgNO₃ + NaCl → AgCl↓ + NaNO₃  
Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl↓ + Na⁺ + NO₃⁻  
**Ag⁺ + Cl⁻ → AgCl↓**

# 2 | Tabela rozpuszczalności — jak czytać

Oznaczenia stosowane w większości podręczników klasy 8 i na konkursach:
- **R** — dobrze rozpuszczalna
- **T** — trudno rozpuszczalna (strąca się przy większym stężeniu)
- **N** — praktycznie nierozpuszczalna (strąca się już z rozcieńczonych roztworów) → osad ↓
- czasem używa się strzałki ↓ zamiast N

**Najważniejsze reguły (do zapamiętania bez tabeli):**
- Wszystkie azotany(V) — R
- Wszystkie sole sodu, potasu i amonu — R
- Większość chlorków — R (wyjątki: AgCl, PbCl₂, Hg₂Cl₂ — N)
- Większość siarczanów(VI) — R (wyjątki: BaSO₄, PbSO₄, CaSO₄, SrSO₄ — N/T)
- Wodorotlenki metali I i II grupy (oprócz Be, Mg) — R; reszta zwykle N
- Węglany, fosforany, siarczki — zwykle N (oprócz metali I grupy i amonu)

# 3 | Strącanie osadów — barwy charakterystyczne

| Osad              | Barwa                  | Typowa reakcja                          |
|-------------------|------------------------|-----------------------------------------|
| AgCl              | biały serowaty         | Ag⁺ + Cl⁻ → AgCl↓                      |
| AgBr              | żółtawobiały           | Ag⁺ + Br⁻                              |
| AgI               | żółty                  | Ag⁺ + I⁻                               |
| BaSO₄             | biały                  | Ba²⁺ + SO₄²⁻ → BaSO₄↓                  |
| CaCO₃             | biały                  | Ca²⁺ + CO₃²⁻                           |
| Cu(OH)₂           | niebieski              | Cu²⁺ + 2OH⁻                            |
| Fe(OH)₂           | zielonkawy / brudnozielony | Fe²⁺ + 2OH⁻                         |
| Fe(OH)₃           | brunatny / rdzawy      | Fe³⁺ + 3OH⁻                            |
| PbI₂              | żółty                  | Pb²⁺ + 2I⁻                             |
| PbCl₂             | biały                  | Pb²⁺ + 2Cl⁻                            |

# 4 | Otrzymywanie soli, gdy substratem jest inna sól

Metody:
1. **sól + kwas** (mocniejszy kwas wypiera słabszy / lotny)  
   Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
2. **sól + zasada**  
   CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄
3. **sól + sól** (podwójna wymiana, gdy powstaje osad lub gaz lub słaby elektrolit)  
   AgNO₃ + NaCl → AgCl↓ + NaNO₃
4. **metal + sól** (reakcja wypierania — patrz X04)

# 5 | Kwas z jego soli

Mocniejszy kwas wypiera słabszy lub lotny z soli:
- węglany + mocny kwas → CO₂
- siarczki + mocny kwas → H₂S
- siarczyny + mocny kwas → SO₂

Przykład:
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑  
jonowo skrócone: CO₃²⁻ + 2H⁺ → H₂O + CO₂↑

# 6 | Wykrywanie jonów (reakcje charakterystyczne)

| Jon     | Odczynnik          | Obserwacja                  | Równanie skrócone          |
|---------|--------------------|-----------------------------|----------------------------|
| Cl⁻     | AgNO₃              | biały osad (rozpuszczalny w NH₃aq) | Ag⁺ + Cl⁻ → AgCl↓     |
| SO₄²⁻   | BaCl₂ lub Ba(NO₃)₂ | biały osad nierozpuszczalny w kwasach | Ba²⁺ + SO₄²⁻ → BaSO₄↓ |
| CO₃²⁻   | kwas (HCl) + woda wapienna | gaz + zmętnienie wody wapiennej | CO₃²⁻ + 2H⁺ → CO₂ + H₂O |
| Cu²⁺    | NaOH               | niebieski osad              | Cu²⁺ + 2OH⁻ → Cu(OH)₂↓ |
| Fe³⁺    | NaOH               | brunatny osad               | Fe³⁺ + 3OH⁻ → Fe(OH)₃↓ |

# 7 | Zadania konkursowe (wzorce)

# Najczęstsze błędy
- pisanie jonów widzów w równaniu skróconym
- brak strzałki ↓ przy osadzie
- mylenie barw osadów (szczególnie Fe(OH)₂ vs Fe(OH)₃)
- stosowanie tabeli rozpuszczalności „na pamięć” zamiast reguł
