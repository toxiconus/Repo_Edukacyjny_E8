# OLIMPIADA_8_MASTER

## Nadrzędny plan przygotowania uczennicy klasy 8 do konkursów i olimpiad

### Chemia • Biologia • Język polski • Matematyka

**Status dokumentu:** MASTER — architektura, mapa projektu i źródła  
**Wersja:** 0.3 (ulepszona)  
**Data aktualizacji:** 2026-10-08  
**Cel:** zbudowanie kompletnego systemu nauki dla klasy 8, który przygotowuje jednocześnie do konkursów przedmiotowych, zadań olimpijskich oraz wyprzedzająco do szkoły ponadpodstawowej.  
**Na tym etapie:** bez pełnych treści lekcji. Dokument określa zakres, strukturę, metodykę, typy materiałów, kolejność pracy oraz **konkretne, zweryfikowane źródła**.

**Zmiany w v0.3 względem v0.2:**
- dodano sekcję konkretnych linków oficjalnych (olimpiady, archiwa, podstawa programowa, kuratoria);
- ujednolicono system ID (CHEM-001…, BIO-001… itd.);
- dodano praktyczną sekcję „Szybki start — gdzie brać zadania teraz”;
- uzupełniono informacje o Olimpiadzie Chemicznej Juniorów (uznanie MEN);
- dodano linki do terminarzy MEN 2025/2026 i 2026/2027;
- doprecyzowano priorytety i zależności;
- dodano statusy elementów i checklistę budowy;
- poprawiono spójność numeracji i strukturę katalogów.

# 1. CEL GŁÓWNY

Projekt ma przygotować uczennicę klasy 8 nie tylko do zapamiętywania materiału, ale do samodzielnego rozwiązywania nowych i trudnych problemów.

Główne cele:

1. bardzo mocne opanowanie podstawy programowej;
2. opanowanie materiału wykraczającego poza standard klasy 8 tam, gdzie daje przewagę konkursową;
3. rozwój rozumowania problemowego;
4. nauka analizy danych, tabel, wykresów, doświadczeń i tekstów;
5. nauka uzasadniania odpowiedzi;
6. systematyczne rozwiązywanie zadań archiwalnych;
7. budowanie banku typowych problemów i sposobów ich rozwiązania;
8. wykrywanie luk i automatyczny powrót do brakujących podstaw;
9. trening pracy pod presją czasu;
10. przygotowanie do dalszego rozwoju w liceum.

Projekt nie powinien być zwykłym „kursem z podręcznika". Ma działać jak osobisty system treningowy.

------------------------------------------------------------------------

# 2. ZASADA DRABINY POZIOMÓW

Każdy temat i każda umiejętność powinny być przypisane do poziomu.

## Poziom 0 — fundament

To, co uczennica musi rozumieć przed rozpoczęciem trudniejszych zadań.

## Poziom 1 — mocna klasa 8

Pełne opanowanie materiału szkolnego + zadania wymagające samodzielnego rozumowania.

## Poziom 2 — konkursowy

Zadania trudniejsze niż typowy sprawdzian, wymagające łączenia kilku wiadomości (konkursy wojewódzkie, Olimpus, etap szkolny olimpiad juniorów).

## Poziom 3 — olimpijski

Zadania archiwalne i zadania o strukturze olimpijskiej (OMJ, Olimpiada Chemiczna Juniorów, etapy okręgowe).

## Poziom 4 — mistrzowski

Problemy wieloetapowe, nietypowe, wymagające samodzielnego znalezienia metody (finały, zadania transferowe).

Nie każdy temat musi dochodzić do poziomu 4. Poziom docelowy zależy od znaczenia tematu.

------------------------------------------------------------------------

# 3. PRIORYTETY A / B / C

Każdy temat otrzymuje priorytet.

## A — obowiązkowy

Materiał konieczny dla dobrego wyniku i fundament kolejnych działów.

## B — bardzo ważny

Często występujący w konkursach albo mocno rozwijający rozumowanie.

## C — rozszerzenie

Materiał przydatny dla najwyższego poziomu, ale niewymagany na każdym etapie.

Dodatkowe oznaczenia:

- **A+** — absolutny rdzeń;
- **B+** — częsty typ olimpijski;
- **O** — specjalny materiał olimpijski;
- **L** — wejście w liceum.

# 5. ZASADA: WIEDZA → ROZUMIENIE → UMIEJĘTNOŚĆ → ZADANIE

Projekt nie może opierać się wyłącznie na teorii.

Każdy ważny temat powinien przejść przez cztery warstwy:

**WIEDZA** — definicje; fakty; wzory; reguły.

**ROZUMIENIE** — dlaczego; zależności; mechanizm; przyczyna i skutek.

**UMIEJĘTNOŚĆ** — obliczenie; analiza; interpretacja; dowód; eksperyment; argumentacja.

**ZADANIE** — zastosowanie w nowej sytuacji.

Najwyższym celem jest umiejętność rozwiązania problemu, którego uczennica wcześniej nie widziała.

matematyka: liczby + algebra + geometria + kombinatoryka.

# 60. ZALEŻNOŚCI GŁÓWNE

```text
OLI: czytanie → analiza → strategia → rozwiązanie → kontrola

CHEMIA:
atom → układ okresowy → elektrony → wiązania → wzory
→ reakcje → kwasy/zasady/sole → roztwory → mol
→ stechiometria → zadania wieloetapowe

BIOLOGIA:
metoda naukowa → komórka → chemia życia → metabolizm
→ genetyka → rośliny/człowiek → ekologia → zadania danych

POLSKI:
czytanie → wnioskowanie → argumentacja → literatura
→ język → lektury → interpretacja → wypowiedź konkursowa

MATEMATYKA:
liczby → algebra → proporcje → geometria
→ kombinatoryka/logika → dowodzenie → zadania olimpijskie
```

# 63. SZYBKI START — GDZIE BRAĆ ZADANIA TERAZ (praktyczna sekcja v0.3)

### Matematyka (najłatwiejszy start)
1. https://www.omj.edu.pl/ — zadania części testowej i zadaniowej OMJ (aktualne + archiwalne).
2. https://archom.ptm.org.pl/ — pełne archiwum Olimpiady Matematycznej (filtruj po poziomie junior / starsze zadania łatwiejsze).

### Chemia
1. https://www.edukator.pl/olimpiada/ — Olimpiada Chemiczna Juniorów (zakres i przykłady).
2. https://www.olchem.edu.pl/ — folder wstępny i zadania Olimpiady Chemicznej (dla ambitnych).
3. Arkusze konkursów wojewódzkich z kuratoriów (szukać „chemia konkurs przedmiotowy” + nazwa województwa).

### Biologia
1. https://www.olimpbiol.pl/ — oficjalna strona, regulamin, zakres.
2. Arkusze konkursów wojewódzkich biologii (kuratoria).

### Polski
1. https://olijpsp.pl — wersja dla szkół podstawowych.
2. https://olijp.pl/ — zagadnienia i przykłady (nawet jeśli głównie dla ponadpodstawowych, tematy interpretacyjne są przydatne).

### Podstawa programowa (sprawdzenie zakresu)
- https://zpe.gov.pl/podstawa-programowa/szkola-podstawowa/chemia
- Analogicznie dla biologii, matematyki, języka polskiego na ZPE / MEN.

### Terminy
- https://www.gov.pl/web/edukacja — aktualne komunikaty o terminach olimpiad.
