# N08 — Mapa przemian „co powstanie?”

**Dział:** Związki nieorganiczne (blok N)  
**Poziomy:** E8 · LO  
**Poprzednia:** N07  
**Następna:** J03 / X01 (zastosowanie)

## KARTA STARTOWA E8 — 10 rzeczy, które muszę umieć

1. Łańcuch: **pierwiastek → tlenek → wodorotlenek / kwas → sól**.
2. Metal + O₂ → tlenek zasadowy → + H₂O → wodorotlenek.
3. Niemetal + O₂ → tlenek kwasowy → + H₂O → kwas.
4. Tlenek zasadowy + kwas → sól + H₂O.
5. Tlenek kwasowy + zasada → sól + H₂O.
6. Wodorotlenek + kwas → sól + H₂O (zobojętnianie).
7. Kwas + metal (reaktywny) → sól + H₂↑.
8. Sól + sól → nowa sól + osad (jeśli trudno rozpuszczalna) — J04.
9. Tlenek amfoteryczny (Al₂O₃, ZnO) reaguje i z kwasem, i z zasadą.
10. Zawsze sprawdzaj bilans i stany (↓ ↑).

### Diagnoza wejściowa

1. Co powstanie z Ca + O₂, a potem z wodą?
2. Co powstanie z SO₃ + H₂O?
3. Zapisz: CaO + HCl.
4. Zapisz: CO₂ + NaOH.
5. Zapisz: NaOH + H₂SO₄.

**Klucz:** 1 CaO, potem Ca(OH)₂; 2 H₂SO₄; 3 CaCl₂ + H₂O; 4 Na₂CO₃ + H₂O (lub NaHCO₃); 5 Na₂SO₄ + H₂O.

**Pytanie przewodnie:** Jak przewidzieć produkt, znając tylko klasę substratu?

## 2. Cele

- Przewiduje produkty przemian między klasami.
- Zapisuje łańcuch pierwiastek → tlenek → wodorotlenek/kwas → sól.
- Dobiera typ reakcji do klas reagentów.

## 3. Mapa przemian (rdzeń)

```
Pierwiastek metal      →  Tlenek zasadowy  →  +H₂O → Wodorotlenek
         │                      │                      │
         │                      + kwas → sól + H₂O     + kwas → sól + H₂O
         │
Pierwiastek niemetal   →  Tlenek kwasowy   →  +H₂O → Kwas
         │                      │                      │
         │                      + zasada → sól + H₂O   + zasada → sól + H₂O
         │
Tlenek amfoteryczny (Al₂O₃, ZnO)  →  reaguje z kwasem I z mocną zasadą
```

## 4. Przykłady prowadzone

**Metal → tlenek → wodorotlenek → sól**  
2Ca + O₂ → 2CaO  
CaO + H₂O → Ca(OH)₂  
Ca(OH)₂ + 2HCl → CaCl₂ + 2H₂O

**Niemetal → tlenek → kwas → sól**  
S + O₂ → SO₂ (lub 2SO₂ + O₂ → 2SO₃)  
SO₃ + H₂O → H₂SO₄  
H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O

**Tlenek zasadowy + kwas**  
MgO + 2HNO₃ → Mg(NO₃)₂ + H₂O

**Tlenek kwasowy + zasada**  
CO₂ + 2NaOH → Na₂CO₃ + H₂O

**Amfoteryczny**  
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O  
Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]

## 5. Ściąga — szybkie reguły

| Substraty | Produkt typowy |
|-----------|----------------|
| metal + tlen | tlenek zasadowy |
| niemetal + tlen | tlenek kwasowy |
| tlenek zasadowy + H₂O | wodorotlenek |
| tlenek kwasowy + H₂O | kwas |
| tlenek zasadowy + kwas | sól + H₂O |
| tlenek kwasowy + zasada | sól + H₂O |
| wodorotlenek + kwas | sól + H₂O |
| kwas + metal (reaktywny) | sól + H₂ |

## 6. Klinika błędów

| Błąd | Popraw |
|------|--------|
| Metal + H₂O zawsze → wodorotlenek | Tylko metale aktywne (grupa 1, Ca…); inne wymagają tlenku |
| CO₂ + H₂O → od razu sól | Najpierw kwas węglowy (słaby) |
| Brak wody w produktach zobojętniania | Zawsze sól + H₂O |
| Al₂O₃ tylko z kwasem | Amfoteryczny — też z mocną zasadą |

## 7. Ćwiczenia z kluczem

1. Uzupełnij łańcuch: Na → ? → ? → NaCl.  
2. Zapisz: ZnO + 2HCl; ZnO + 2NaOH + H₂O.  
3. Co powstanie: P₂O₅ + H₂O; P₂O₅ + 6NaOH.  
4. Przewidź produkty: BaO + H₂SO₄; SO₂ + KOH.

**Klucz:**  
1. Na₂O → NaOH → NaCl (+H₂O).  
2. ZnCl₂ + H₂O; Na₂[Zn(OH)₄] (lub analog).  
3. H₃PO₄; Na₃PO₄ + H₂O.  
4. BaSO₄ + H₂O; K₂SO₃ + H₂O (lub KHSO₃).

## 8. Test (3+2+2+1)

A. Zapisz łańcuch kompletny dla Mg do MgSO₄ (przez tlenek i wodorotlenek).  
B. Prawda/fałsz: a) Tlenek kwasowy + zasada → sól + H₂O. b) Wszystkie metale dają wodorotlenek z wodą.  
C. Zapisz reakcje Al₂O₃ z HCl i z NaOH (wodny).  
D. Po co istnieje mapa przemian?

**Klucz:** A: 2Mg+O₂→2MgO; MgO+H₂O→Mg(OH)₂; Mg(OH)₂+H₂SO₄→MgSO₄+2H₂O. B: P, F. C: Al₂O₃+6HCl→2AlCl₃+3H₂O; Al₂O₃+2NaOH+3H₂O→2Na[Al(OH)₄]. D: przewidywanie produktów bez uczenia się każdej reakcji osobno.

## 9. Słownik

| Termin | Definicja |
|--------|-----------|
| Tlenek zasadowy | Tlenek metalu reagujący z kwasami / wodą → wodorotlenek |
| Tlenek kwasowy | Tlenek niemetalu reagujący z zasadami / wodą → kwas |
| Mapa przemian | Schemat reakcji między klasami związków |
