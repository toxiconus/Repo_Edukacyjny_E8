# J03 — Reakcje jonowe

**Dział:** Chemia jonowa (blok J)  
**Poziomy:** E8 · LO  
**Poprzednia:** J01 / J02  
**Następna:** J04 (strącanie)

## KARTA STARTOWA E8 — 10 rzeczy, które muszę umieć

1. Równanie cząsteczkowe → pełne jonowe → skrócone jonowe.
2. Mocne elektrolity rozpuszczone rozpisujemy na jony.
3. Osady, gazy, woda, słabe elektrolity — zostawiamy cząsteczkowo.
4. Jony obserwatorowe (spectator ions) skracamy.
5. Po skróceniu sprawdzamy bilans atomów **i** ładunków.
6. Reakcja zachodzi, gdy powstaje: osad ↓, gaz ↑, woda lub słaby elektrolit.
7. Samo „zamienienie partnerów” bez produktu usuwającego jony ≠ reakcja netto.
8. Zobojętnianie skrócone: H⁺ + OH⁻ → H₂O (lub H₃O⁺ + OH⁻ → 2H₂O).
9. Strącanie: Ag⁺ + Cl⁻ → AgCl↓.
10. Węglan + kwas: CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O.

### Diagnoza wejściowa

1. Zapisz skrócone jonowe: AgNO₃ + NaCl.
2. Jakie jony są obserwatorowe w tej reakcji?
3. Zapisz skrócone: HCl + NaOH.
4. Czy NaCl + KNO₃ dają reakcję netto? Dlaczego?
5. Co napędza reakcję jonową w roztworze?

**Klucz:** 1 Ag⁺+Cl⁻→AgCl↓; 2 Na⁺, NO₃⁻; 3 H⁺+OH⁻→H₂O; 4 nie — wszystko rozpuszczone; 5 powstanie osadu/gazu/wody/słabego elektrolitu.

**Pytanie przewodnie:** Jak zapisać tylko to, co naprawdę się zmienia w roztworze?

## 2. Cele

- Rozróżnia równanie cząsteczkowe, pełne jonowe i skrócone.
- Rozpoznaje i skraca jony obserwatorowe.
- Decyduje, czy reakcja zachodzi (osad, gaz, H₂O, słaby elektrolit).
- Zachowuje bilans atomów i ładunków.

## 3. Procedura (krok po kroku)

1. Zapisz i zbilansuj równanie **cząsteczkowe**.
2. Oznacz stany: (aq), (s), (g), (l).
3. Rozpisz na jony **tylko** mocne elektrolity rozpuszczone.
4. Zostaw nietknięte: osad, gaz, wodę, słabe elektrolity.
5. Skróć jony występujące po obu stronach (obserwatorowe).
6. Sprawdź bilans atomów i ładunków.

## 4. Przykłady prowadzone

**Osad**  
Cząst.: AgNO₃(aq) + NaCl(aq) → AgCl(s)↓ + NaNO₃(aq)  
Pełne: Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl(s) + Na⁺ + NO₃⁻  
Skrócone: Ag⁺(aq) + Cl⁻(aq) → AgCl(s)↓

**Zobojętnianie**  
Cząst.: HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)  
Skrócone: H⁺(aq) + OH⁻(aq) → H₂O(l)  
(dokładniej: H₃O⁺ + OH⁻ → 2H₂O)

**Gaz (węglan + kwas)**  
CO₃²⁻ + 2H⁺ → CO₂(g)↑ + H₂O(l)  
Uwaga: pęcherzyki to obserwacja — sam fakt wydzielania gazu nie mówi, jaki to gaz. CO₂ potwierdza próba z wodą wapienną (mętnienie).

**Brak reakcji**  
NaCl(aq) + KNO₃(aq) → brak osadu/gazu/słabego elektrolitu → brak reakcji netto.

## 5. Ściąga — kiedy zachodzi?

| Produkt usuwający jony | Przykład skrócony |
|------------------------|-------------------|
| Osad ↓ | Ba²⁺ + SO₄²⁻ → BaSO₄↓ |
| Gaz ↑ | CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O |
| Woda | H⁺ + OH⁻ → H₂O |
| Słaby elektrolit | H⁺ + CH₃COO⁻ → CH₃COOH |

## 6. Klinika błędów

| Błąd | Popraw |
|------|--------|
| Rozpisanie osadu na jony | Zostaw AgCl(s) |
| Zostawienie jonów obserwatorowych | Skróć |
| Brak bilansu ładunku | Sprawdź sumę |
| „Zawsze jest reakcja po zmieszaniu” | Sprawdź produkt |

## 7. Ćwiczenia z kluczem

1. BaCl₂ + Na₂SO₄ → skrócone.  
2. HNO₃ + KOH → skrócone.  
3. Na₂CO₃ + 2HCl → skrócone.  
4. Wskaż obserwatorowe w AgNO₃ + KBr.  
5. Czy KCl + NaNO₃ dają reakcję? Uzasadnij.

**Klucz:**  
1. Ba²⁺ + SO₄²⁻ → BaSO₄↓  
2. H⁺ + OH⁻ → H₂O  
3. CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O  
4. K⁺, NO₃⁻  
5. Nie — wszystkie sole dobrze rozpuszczalne, brak produktu usuwającego jony.

## 8. Test (3+2+2+1)

A. Zapisz skrócone: Pb(NO₃)₂ + 2KI; H₂SO₄ + 2NaOH; CaCO₃ + 2HCl.  
B. Prawda/fałsz: a) Jony obserwatorowe biorą udział w reakcji. b) Powstanie wody napędza zobojętnianie.  
C. Popraw zapis: Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl + Na⁺ + NO₃⁻ (co skrócić?).  
D. Dlaczego nie rozpisujemy H₂O na jony w zobojętnianiu?

**Klucz:** A: Pb²⁺+2I⁻→PbI₂↓; H⁺+OH⁻→H₂O; CO₃²⁻+2H⁺→CO₂↑+H₂O. B: F, P. C: skrócić Na⁺ i NO₃⁻. D: woda jest produktem (słaby elektrolit / cząsteczka), nie rozpisujemy.

## 9. Słownik

| Termin | Definicja |
|--------|-----------|
| Równanie cząsteczkowe | Wzory cząsteczek / wzorów sumarycznych |
| Równanie pełne jonowe | Wszystkie jony mocnych elektrolitów rozpisane |
| Równanie skrócone jonowe | Tylko jony i cząsteczki biorące udział |
| Jon obserwatorowy | Jon obecny po obu stronach, nie zmienia się |

## Reakcje jonowe — materiał wstępny

### TREŚĆ KANONICZNA PO W1 — RÓWNANIA JONOWE

Równanie jonowe skrócone zapisuje tylko te jony lub cząsteczki, które rzeczywiście uczestniczą w przemianie. Aby je otrzymać, zapisz i zbilansuj równanie cząsteczkowe, rozpisz na jony mocne elektrolity rozpuszczone w wodzie, pozostaw osady, gazy, wodę i słabe elektrolity w postaci cząsteczkowej, a następnie skróć jony obserwatorów występujące po obu stronach.

#### Strącanie

AgNO₃(aq) + NaCl(aq) → AgCl(s)↓ + NaNO₃(aq)

Po skróceniu: Ag⁺(aq) + Cl⁻(aq) → AgCl(s)↓.

#### Neutralizacja

HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)

Zapis jonowy skrócony: H⁺(aq) + OH⁻(aq) → H₂O(l), albo dokładniej w wodzie: H₃O⁺ + OH⁻ → 2H₂O.

#### Wydzielanie gazu

Dla reakcji węglanu z kwasem zapis jonowy skrócony może mieć postać: CO₃²⁻ + 2H⁺ → CO₂(g)↑ + H₂O(l). Równanie zachowuje liczbę atomów i ładunek. W praktyce wydzielanie pęcherzyków jest obserwacją; identyfikacja gazu wymaga odpowiedniej próby.

#### Kiedy reakcja zachodzi?

Reakcja jonowa zachodzi, gdy jony tworzą produkt, który opuszcza roztwór jako osad, gaz lub słaby elektrolit, np. wodę, albo gdy inny proces jest uzasadniony warunkami. Po skróceniu nie powinny pozostać niezmienione jony obserwatorów. Zawsze sprawdź bilans atomów i ładunku.

### W22 — kontrola równań jonowych (2026-10-09, GPT-6)

- **Sprawdzono:** `Ag⁺ + Cl⁻ → AgCl(s)↓`, `H⁺ + OH⁻ → H₂O` (skrót szkolny) oraz `CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O` — bilans atomów i ładunku jest zachowany.
- **Doprecyzowanie:** obserwacja wydzielania gazu sama nie identyfikuje go; potrzebna jest właściwa próba. W pełnym zapisie wodnym neutralizację można przedstawić jako `H₃O⁺ + OH⁻ → 2H₂O`.
- **Ograniczenie:** kontrola wybranych równań, nie pełna walidacja wszystkich kluczy.
