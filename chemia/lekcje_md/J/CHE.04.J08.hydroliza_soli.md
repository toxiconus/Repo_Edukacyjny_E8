# J08 — Hydroliza soli

**Dział:** Chemia jonowa (blok J)  
**Poziomy:** LO  
**Poprzednia:** J07  
**Następna:** J09 (bufory)

## KARTA STARTOWA LO — 10 rzeczy, które muszę umieć

1. Hydroliza = reakcja jonów soli z wodą.
2. Sól z mocnego kwasu + mocnej zasady → odczyn obojętny (brak hydrolizy).
3. Sól z mocnego kwasu + słabej zasady → odczyn kwasowy (hydroliza kationowa).
4. Sól ze słabego kwasu + mocnej zasady → odczyn zasadowy (hydroliza anionowa).
5. Sól ze słabego kwasu + słabej zasady → zależy od Ka/Kb.
6. Przykład anionowa: CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻ → pH > 7.
7. Przykład kationowa: NH₄⁺ + H₂O ⇌ NH₃ + H₃O⁺ → pH < 7.
8. Przewidywanie: porównaj „siłę” kwasu i zasady, z których sól powstała.
9. (obliczenia) Kh = Kw / Ka lub Kw / Kb; [H₃O⁺] lub [OH⁻] ≈ √(Kh·c).
10. Nie mylić hydrolizy z dysocjacją samej soli.

### Diagnoza wejściowa

1. Jaki odczyn ma roztwór NaCl?
2. Jaki odczyn ma roztwór CH₃COONa?
3. Jaki odczyn ma roztwór NH₄Cl?
4. Zapisz hydrolizę CH₃COO⁻.
5. Zapisz hydrolizę NH₄⁺.

**Klucz:** 1 obojętny; 2 zasadowy; 3 kwasowy; 4 CH₃COO⁻+H₂O⇌CH₃COOH+OH⁻; 5 NH₄⁺+H₂O⇌NH₃+H₃O⁺.

**Pytanie przewodnie:** Dlaczego niektóre sole dają roztwór kwaśny, a inne zasadowy, choć „to tylko sól”?

## 2. Cele

- Przewiduje odczyn roztworu soli na podstawie pochodzenia kwasu i zasady.
- Zapisuje równania hydrolizy.
- (wstęp) Stosuje Kh do obliczeń.

## 3. Reguły przewidywania

| Kwas \ Zasada | Mocna | Słaba |
|---------------|-------|-------|
| **Mocny** | obojętny | kwasowy |
| **Słaby** | zasadowy | zależy od Ka vs Kb |

## 4. Przykłady prowadzone

**Anionowa (CH₃COONa)**  
CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻ → odczyn zasadowy

**Kationowa (NH₄Cl)**  
NH₄⁺ + H₂O ⇌ NH₃ + H₃O⁺ → odczyn kwasowy

**Obojętna (NaCl)**  
Na⁺ i Cl⁻ nie hydrolizują (pochodzą z mocnych).

**Obie (CH₃COONH₄)**  
Porównaj Ka(CH₃COOH) i Kb(NH₃) — podobne → prawie obojętny.

## 5. Klinika błędów

| Błąd | Popraw |
|------|--------|
| „Wszystkie sole dają odczyn obojętny” | Tylko mocny+mocny |
| Hydroliza = dysocjacja soli | Hydroliza to reakcja z H₂O |
| Zły kierunek strzałki | ⇌ (równowaga) |

## 6. Ćwiczenia z kluczem

1. Odczyn: KNO₃, HCOONa, NH₄NO₃, Na₂CO₃.  
2. Zapisz hydrolizę CO₃²⁻ (I etap).  
3. Dlaczego roztwór AlCl₃ jest kwaśny?  
4. (obliczeniowe) Kh dla soli słabego kwasu Ka=1·10⁻⁵.

**Klucz:**  
1. obojętny; zasadowy; kwasowy; zasadowy.  
2. CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻  
3. Al³⁺ hydrolizuje (kation słabej zasady / kompleks).  
4. Kh = Kw/Ka = 1·10⁻⁹

## 7. Test (3+2+2+1)

A. Odczyn i uzasadnienie: Na₂SO₄, CH₃COOK, NH₄Br.  
B. Prawda/fałsz: a) Sól mocnego kwasu i słabej zasady → kwasowy. b) Hydroliza zawsze całkowita.  
C. Zapisz hydrolizę F⁻.  
D. Po co znać hydrolizę?

**Klucz:** A: obojętny; zasadowy; kwasowy. B: P, F. C: F⁻+H₂O⇌HF+OH⁻. D: przewidywanie odczynu roztworów soli (ważne w analizie i buforach).

## 8. Słownik

| Termin | Definicja |
|--------|-----------|
| Hydroliza soli | Reakcja jonów soli z wodą |
| Hydroliza anionowa | Anion słabego kwasu + H₂O → OH⁻ |
| Hydroliza kationowa | Kation słabej zasady + H₂O → H₃O⁺ |
| Kh | Stała hydrolizy |
