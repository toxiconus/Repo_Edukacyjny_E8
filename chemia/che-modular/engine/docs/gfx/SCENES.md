# Katalog scen GFX

Scena = gotowy zestaw naczyń + efektów. W MD: `gfx.scene: carbonate`.


## `acidMetal` — Metal + kwas

Próbówka/zlewka: metal + kwas → pęcherzyki H₂, ewentualnie ciepło.

- naczynia: testTube, beaker
- efekty: bubbles, liquid, heatGlow
- domeny: acids, oxides

## `indicator` — Wskaźnik w roztworze

Roztwór + wskaźnik — zmiana barwy cieczy.

- naczynia: beaker, testTube
- efekty: liquid, dropMix
- domeny: acids, hydroxides, salts

## `indicatorRack` — Zestaw wskaźników

Szereg probówek z różnymi wskaźnikami / pH.

- naczynia: testTube, tubeRack
- efekty: liquid, label
- domeny: acids

## `titration` — Miareczkowanie

Biureta nad kolbą — krople, menisk, zmiana barwy punktu końcowego.

- naczynia: burette, flask, stand
- efekty: liquid, meniscus, dropMix, tap
- domeny: acids

## `dilution` — Rozcieńczanie

Przenoszenie roztworu do kolby miarowej, dopełnienie wodą.

- naczynia: volFlask, beaker, pipette
- efekty: liquid, meniscus
- domeny: acids

## `conductivity` — Przewodnictwo

Elektrody w roztworze — żarówka / wskaźnik przewodnictwa.

- naczynia: beaker, conductivity
- efekty: liquid, label
- domeny: salts, acids

## `gasCollection` — Zbieranie gazu

Gaz zbierany nad wodą lub w cylindrze.

- naczynia: testTube, gasCollect
- efekty: bubbles, liquid
- domeny: oxides, acids

## `carbonate` — Węglan + kwas / CO₂

Węglan + kwas → burzliwe CO₂, ewentualnie mętnienie wody wapiennej.

- naczynia: testTube, beaker
- efekty: bubbles, liquid, turbidity
- domeny: oxides, salts

## `heating` — Ogrzewanie

Naczynie nad płomieniem — para, poświata, ewentualna zmiana barwy osadu.

- naczynia: testTube, burner, stand
- efekty: flame, heatGlow, steam
- domeny: oxides, hydroxides, salts
