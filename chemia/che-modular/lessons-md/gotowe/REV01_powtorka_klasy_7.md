::: minimum | Muszę umieć — 10 punktów
1. **Z = liczba protonów** (w atomie obojętnym także elektronów); **A = protony + neutrony**; **n⁰ = A − Z**. Liczba protonów definiuje pierwiastek.
2. **Jon:** kation oddał elektrony (ładunek +), anion przyjął (ładunek −); ładunek jonu = p⁺ − e⁻.
3. **Układ okresowy** jest ułożony według rosnącego **Z**; okres = liczba powłok, grupa = podobna zewnętrzna powłoka (grupy 1, 2, 13–18: 1, 2, 3–8 elektronów walencyjnych).
4. **Wartościowość** to liczba wiązań atomu w danym związku: **H–I, O–II, Al–III, C–IV**; Na, K — I; Mg, Ca — II; Fe, Cu i inne o zmiennej wartościowości — podajemy w nazwie.
5. **Wzór z wartościowości:** W–K–S–K (wartościowości → krzyżowanie → skracanie → kontrola).
6. **Nawias** przy powtarzającej się grupie atomów: Ca(OH)₂, Al₂(SO₄)₃ — nigdy CaOH₂.
7. **Wiązania:** metal + niemetal → najczęściej jonowe; niemetal + niemetal → kowalencyjne (różne — spolaryzowane, takie same — niespolaryzowane); metale → metaliczne.
8. **Bilansowanie:** zmieniamy tylko **współczynniki**, nigdy indeksów; prawo zachowania masy.
9. **Typy reakcji:** synteza, analiza, wypieranie, podwójna wymiana, spalanie; egzo- i endotermiczne.
10. **Nie mieszaj:** wartościowość ≠ stopień utlenienia ≠ ładunek jonu ≠ indeks ≠ współczynnik; A ≠ masa atomowa ≠ masa cząsteczkowa.
:::

## 0.1 | Jak pracować z lekcją {#jak-pracowac}

::: karta understand
- **Najpierw odpowiadaj, potem sprawdzaj.** Błąd teraz = zysk później.
- **Kolejność myślenia zawsze ta sama:** atom → jon → wartościowość / ładunek → wzór → wiązanie → równanie.
- **Przy każdym wzorze rób kontrolę** (łączna wartościowość albo suma ładunków = 0). Przy każdym równaniu — policz atomy po obu stronach.
- **Zasada 80/20:** wartościowość + W–K–S–K + nawias + bilans współczynnikami dają większość punktów z fundamentów.
:::

## 0.2 | Mapa lekcji i pułapki {#mapa}

**Plan pracy:** 1) przypomnij — atom, jon, układ okresowy; 2) opanuj — wartościowość i układanie wzorów; 3) zastosuj — wiązania, typy reakcji, bilansowanie, ćwiczenia, zadania konkursowe.

**Przebieg:** BHP i atom → jon → układ okresowy → wartościowość → wzory → wiązania → równania → strategie → klinika błędów → ćwiczenia → konkurs.

::: karta warning | Pułapki podstawowe
- zmienianie indeksów przy bilansowaniu,
- Fe / Cu bez podania wartościowości w nazwie,
- mylenie liczby atomowej z masową (oraz z masą atomową z układu),
- FeO₃ zamiast Fe₂O₃,
- brak nawiasu przy powtarzającej się grupie atomów.
:::

## 0.3 | Mapa skojarzeń — warsztat chemika {#skojarzenia}

Przeczytaj raz, wróć po tygodniu. To „folder” w głowie, do którego wkładasz resztę wiedzy.

| Pojęcie | Skojarzenie |
|---|---|
| Atom | narzędzie na stole: protony i neutrony w „pudełku” (jądrze), elektrony wokół jak muchy wokół lampy |
| Jon | to samo narzędzie, ale naładowane: kation oddał elektron, anion przyjął |
| Układ okresowy | tablica narzędzi ułożona według rosnącej liczby atomowej Z; izotopy jednego pierwiastka mają różne A, ale to samo miejsce |
| Wartościowość | liczba „rąk”, którymi atom łączy się z innymi (H — 1, O — 2, Al — 3, C — 4); wiązanie podwójne liczymy jako dwa |
| Wzór sumaryczny | „uścisk dłoni” — liczba rąk po obu stronach musi się zgadzać |
| Wzór strukturalny | rysunek „kto z kim trzyma się za ręce” (kreski zamiast indeksów) |
| Wzór elektronowy | to samo, ale kropki zamiast kresek — widać elektrony walencyjne |
| Wiązanie jonowe | przekazanie elektronów → jony + i − przyciągają się (najczęściej metal + niemetal) |
| Wiązanie kowalencyjne | uwspólnienie elektronów (niemetal + niemetal) |
| Wiązanie metaliczne | dodatnie jony metalu w „morzu elektronów” |
| Równanie reakcji | przepis: substraty → produkty; nic nie znika, wszystko się przekształca |

::: karta core | Jedno zdanie do zapamiętania
Atom może tworzyć wiązania. **Wartościowość mówi, iloma „rękami” atom łączy się z innymi atomami; wzór pokazuje, czy liczba tych rąk się zgadza.**
:::

## 1 | BHP i szkło laboratoryjne [[basic:E8]] {#bhp}

::: karta core | Zasady obowiązkowe
- Nie smakujemy substancji. Zapach — tylko na polecenie nauczyciela, **wachlowaniem** (dłonią kierujemy pary ku nosowi, nie przykładamy nosa do naczynia).
- Środki ochrony wskazane przez nauczyciela i wynikające z zagrożeń: okulary, fartuch; rękawice, gdy są właściwe dla substancji.
- Ogrzewanie w probówce — wylot od siebie i innych.
- Nie pipetujemy ustami — gruszka lub pipetor.
- Rozcieńczając kwas: **kwas do wody**, nigdy odwrotnie.
- Przed użyciem odczynnika czytamy etykietę i piktogramy zagrożeń.
- Rozlanie, kontakt z oczami lub skórą — natychmiast zgłaszamy nauczycielowi i płuczemy dużą ilością wody zgodnie z jego poleceniem.
- Nie wylewamy substancji niebezpiecznych do zlewu bez konsultacji; sprzątamy stanowisko.
:::

::: karta understand | Dlaczego „kwas do wody”?
Rozcieńczanie kwasu wydziela dużo ciepła. Woda wlana do stężonego kwasu może lokalnie zagotować się i spowodować gwałtowne rozpryski kwasu. Wlewanie kwasu do wody małymi porcjami, z mieszaniem, jest bezpieczniejsze.
:::

**Dodatkowo:** nie ogrzewaj zamkniętych naczyń; nie wlewaj odczynników z powrotem do butelki; poznaj kartę charakterystyki (SDS); nie jedz i nie pij w pracowni; umyj ręce po pracy; nie używaj uszkodzonego szkła; nie zostawiaj palnika bez opieki; znaj drogi ewakuacyjne i miejsce apteczki.

**Skróty:** kwas → do wody · zapach → wachluj · kontakt → płucz wodą. **NIE** smakuj, **NIE** pipetuj ustami, **NIE** kieruj probówki ku sobie, **NIE** wylewaj bez konsultacji.

| Naczynie | Zastosowanie |
|---|---|
| Probówka | małe ilości substancji, ogrzewanie, reakcje |
| Zlewka | mieszanie, ogrzewanie, orientacyjne odmierzanie cieczy |
| Kolba stożkowa (Erlenmeyera) | mieszanie, miareczkowanie |
| Kolba okrągłodenna | ogrzewanie cieczy i reakcje; element zestawu do destylacji |
| Pipeta | przenoszenie objętości (miarowa — precyzyjnie; Pasteura — krople) |
| Biureta | precyzyjne dozowanie cieczy (miareczkowanie) |
| Cylinder miarowy | odmierzanie objętości cieczy |
| Parownica | odparowywanie cieczy, prażenie |
| Tygiel | prażenie w wysokiej temperaturze |
| Moździerz | rozdrabnianie substancji stałych |
| Eksykator | przechowywanie w suchym środowisku |
| Chłodnica | skraplanie par w destylacji |

## 2 | Budowa atomu, izotopy, jony [[basic:E8]] {#atom}

| Cząstka | Ładunek | Masa (ok.) | Miejsce |
|---|---|---|---|
| Proton p⁺ | +1 | 1 u | jądro |
| Neutron n⁰ | 0 | 1 u | jądro |
| Elektron e⁻ | −1 | ok. 1/1836 u | powłoki |

::: regula
**Z = p⁺** (w atomie obojętnym także e⁻) · **A = p⁺ + n⁰** · **n⁰ = A − Z** — „z całości odejmij protony, zostaną neutrony”.
:::

**Liczba protonów definiuje pierwiastek.** Każdy atom z 8 protonami to tlen, każdy z 17 — chlor. Jon może mieć inną liczbę elektronów, izotop — inną liczbę neutronów, ale o tym, jaki to pierwiastek, decyduje liczba protonów.

::: karta warning | Pułapka: A to nie masa atomowa
Liczba masowa **A** jest liczbą całkowitą dla konkretnego **izotopu**. **Masa atomowa** z układu okresowego jest zwykle liczbą dziesiętną — to średnia ważona mas izotopów występujących w przyrodzie.
:::

**Izotopy** — atomy tego samego pierwiastka: ta sama liczba protonów, różna liczba neutronów (i liczba masowa). Przykłady: ¹H, ²H, ³H; ¹²C, ¹³C, ¹⁴C. Izotopy atomów obojętnych mają też tyle samo elektronów. **Jon zmienia liczbę elektronów, izotop — liczbę neutronów.**

**Jon** — atom albo **grupa atomów** mająca ładunek elektryczny, bo oddała lub przyjęła elektrony.
- **Kation** — ładunek dodatni (oddał elektrony): Na⁺ (11 p, 10 e), Al³⁺ (13 p, 10 e).
- **Anion** — ładunek ujemny (przyjął elektrony): Cl⁻ (17 p, 18 e), S²⁻ (16 p, 18 e), SO₄²⁻ (wieloatomowy).

::: karta core | Algorytm liczenia elektronów w jonie
1. Odczytaj Z — to liczba protonów.
2. Atom obojętny: e⁻ = Z.
3. Ładunek **dodatni** — odejmij elektrony (Al³⁺: 13 − 3 = 10 e⁻).
4. Ładunek **ujemny** — dodaj elektrony (S²⁻: 16 + 2 = 18 e⁻).

**Kontrola:** ładunek jonu = p⁺ − e⁻ · Na⁺: 11 − 10 = +1 · Cl⁻: 17 − 18 = −1 · O²⁻: 8 − 10 = −2.
**Reguła główna: kation oddał, anion przyjął.**
:::

## 3 | Układ okresowy [[basic:E8]] {#uklad}

- **Okresy** (wiersze) — numer okresu = liczba powłok elektronowych atomu. Sód leży w 3. okresie: elektrony na trzech powłokach (2, 8, 1). *Dotyczy atomu obojętnego w stanie podstawowym.*
- **Kontrprzykład:** jon Na⁺ ma układ 2, 8 (dwie powłoki), ale pochodzi od sodu z 3. okresu — numer okresu dotyczy atomu pierwiastka, nie jonu.
- **Grupy** (kolumny) — podstawowa numeracja **1–18**; dla grup głównych spotkasz też dawne IA–VIIIA.
- Układ jest ułożony według **rosnącej liczby atomowej Z**, a nie liczby masowej A.

**Elektrony walencyjne** to elektrony najbardziej zewnętrznej zajętej powłoki — to one tworzą wiązania. W grupach głównych: **1, 2**, a w grupach **13–18** kolejno **3–8** (numer 13 nie oznacza 13 elektronów).

| Grupa | e⁻ walencyjne | Rodzina | Typowe wartościowości w zadaniach szkolnych |
|---|---|---|---|
| 1 | 1 | metale alkaliczne (litowce) | I |
| 2 | 2 | metale ziem alkalicznych | II |
| 13 | 3 | borowce | III |
| 14 | 4 | węglowce | IV |
| 15 | 5 | azotowce | III lub V |
| 16 | 6 | chalkogeny (tlenowce) | II, IV lub VI |
| 17 | 7 | fluorowce | I wobec metali i wodoru |
| 18 | 8 (He: 2) | gazy szlachetne | w zadaniach szkolnych zwykle niewartościowe |

Tabela to skrót dla najczęstszych pierwiastków. **Gdy nazwa związku podaje wartościowość — stosuj informację z nazwy.**

::: nie-myl
**Grupa ≠ wartościowość** (przykład chloru): numer grupy — 17; elektrony walencyjne — 7; wartościowość — I w HCl i wobec metali, w związkach z tlenem możliwe inne. Nie twórz reguły „grupa 17 = wartościowość XVII”.
:::

**Skąd nazwy:** *atomos* (gr.) — „niepodzielny”; *ion* — „wędrujący” (jony wędrują w roztworze podczas przepływu prądu); kation — idzie ku katodzie (+), anion — ku anodzie (−); alkaliczne — od alkaliów (zasad: NaOH, KOH); fluorowce (halogeny) — „tworzące sole” (NaCl); chalkogeny — „tworzące rudy”; gazy szlachetne — dawniej uważane za niemal niereaktywne.

## 4 | Wartościowość — kluczowy temat [[basic:E8]] {#wartosciowosc}

::: regula
**Wartościowość** (model szkolny) to liczba wiązań, które atom tworzy z innymi atomami w danym związku; wiązanie podwójne liczymy jako dwa, potrójne jako trzy. Zapis cyfrą rzymską: O(II), Al(III), Fe(II) lub Fe(III).
:::

> W bardziej zaawansowanej chemii opis wiązań jest bogatszy (IUPAC rozróżnia wartościowość i stopień utlenienia). W klasie 7/8 wartościowość to narzędzie do układania wzorów i rysowania wiązań.

**Model „liczby rąk”:** H(I) — 1 ręka, O(II) — 2, Al(III) — 3, C(IV) — 4. We wzorze wszystkie ręce muszą zostać wykorzystane. Dlatego Ca(II) i O(II) tworzą CaO, a nie Ca₂O₂ — stosunek 1 : 1 jest już najprostszy.

::: karta core | Test równowagi wartościowości
- Al₂O₃: 2 · III = 6 i 3 · II = 6 → wzór poprawny.
- AlO: 1 · III ≠ 1 · II → wzór niepoprawny.
- Ca₂O₂: wartościowości się równoważą, ale wzór trzeba **skrócić** do CaO.
:::

**Pierwiastek nie ma jednej wartościowości „na zawsze”.** W H₂S siarka tworzy 2 wiązania (II), w SO₂ — 4 (IV), w SO₃ — 6 (VI).

**Jak ustalić wartościowość:** 1) z układu okresowego (grupy główne); 2) ze znanego wzoru — łączna wartościowość obu składników musi być równa (CO₂: dwa atomy O · II = IV → C ma IV); 3) z nazwy (tlenek żelaza(III)).

| Pierwiastek | Wartościowość | Uwagi |
|---|---|---|
| H | I | model szkolny |
| O | II (najczęściej) | wyjątki (nadtlenki) — później |
| Na, K | I | grupa 1 |
| Mg, Ca | II | grupa 2 |
| Al | III | grupa 13 |
| C | IV | grupa 14 |
| N, P | III / V | P względem H zwykle III, maks. względem O — V |
| S | II / IV / VI | zależnie od związku |
| Cl | I (chlorki) | III, V, VII w związkach tlenowych — rozszerzenie |
| Fe | II / III | **podawać w nazwie** |
| Cu | I / II | **podawać w nazwie** |
| Sn, Pb | II / IV | **podawać w nazwie** |
| Mn | II / IV / VII | **podawać w nazwie** |
| Cr | II / III / VI | **podawać w nazwie** |

**Skrót główny: H–I, O–II, Al–III, C–IV** — „wodór raz, tlen dwa, glin trzy, węgiel cztery”.

::: karta extra | Wartościowość maksymalna
Najwyższa wartościowość pierwiastka w związkach. Dla grup głównych maksymalna wartościowość względem tlenu jest często równa numerowi grupy w **dawnym zapisie A** (I–VII), a nie numerowi 1–18: Al — III, C — IV, P — V, S — VI, Cl — VII (np. HClO₄).
:::

::: nie-myl
**Wartościowość** — liczba wiązań (model „rąk”). **Stopień utlenienia** — umowny ładunek atomu przy założeniu całkowitego przesunięcia elektronów. **Ładunek jonu** — rzeczywisty ładunek atomu lub grupy (Ca²⁺, SO₄²⁻). W prostych zadaniach wyniki wyglądają podobnie, ale to **nie są pojęcia tożsame**.
:::

## 5 | Wzory sumaryczne, grupy atomów, wzory strukturalne [[basic:E8]] {#wzory}

**Wzór sumaryczny** pokazuje rodzaje pierwiastków w substancji i liczbę atomów każdego z nich: H₂O — dwa atomy wodoru i jeden atom tlenu; Al₂O₃ — dwa atomy glinu i trzy atomy tlenu w jednostce wzoru.

::: karta core | Algorytm W–K–S–K
**Najpierw idea:** liczba „rąk” użytych przez jeden pierwiastek musi równać się liczbie rąk drugiego. Al(III) i O(II): najmniejsza wspólna liczba to 6 → 2 Al i 3 O → Al₂O₃. **Krzyżowanie to skrót do tej równowagi, nie magiczna sztuczka.**

**W** — wartościowości (cyfry rzymskie nad symbolami) · **K** — krzyżuj (wartościowość jednego → indeks drugiego) · **S** — skracaj (przez NWD) · **K** — kontrola (łączna wartościowość po obu stronach równa).
:::

| Krok | Al + O | Ca + O | Ca + OH |
|---|---|---|---|
| Wartościowości | Alᴵᴵᴵ Oᴵᴵ | Caᴵᴵ Oᴵᴵ | Caᴵᴵ (OH)ᴵ |
| Krzyżowanie | Al₂O₃ | Ca₂O₂ | Ca₁(OH)₂ |
| Skracanie / indeks 1 | brak wspólnego dzielnika → Al₂O₃ | ÷ 2 → CaO | indeks 1 pomijamy → Ca(OH)₂ |
| Kontrola | 2·III = 6 = 3·II | 1·II = 1·II | 1·II = 2 = 2·I |

**Dwa sposoby, ten sam wynik:** wartościowość — Ca(II) i Cl(I) → CaCl₂; ładunki jonów — Ca²⁺ i Cl⁻, suma ładunków 0 → CaCl₂.

| Sytuacja | Najwygodniejsza metoda | Przykład |
|---|---|---|
| Proste tlenki, związki kowalencyjne | wartościowość | Al(III) i O(II) → Al₂O₃ |
| Sole i wodorotlenki z jonami | ładunki jonów | Ca²⁺ i 2 OH⁻ → Ca(OH)₂ |
| Nazwa z cyfrą rzymską | informacja z nazwy | chlorek żelaza(III) → FeCl₃ |

::: karta core | Reguła „cały klocek” i nawias
Jeśli występuje jon wieloatomowy (OH⁻, SO₄²⁻, NO₃⁻), traktuj go przy krzyżowaniu jak **jeden klocek**: Al³⁺ + SO₄²⁻ → Al₂(SO₄)₃; kontrola: 2·(+3) + 3·(−2) = 0.
**Nawias** stawiamy, gdy indeks dotyczy całej grupy i jest większy od 1: NaOH (jedno OH) · Ca(OH)₂ (dwa OH) · Al₂(SO₄)₃ (trzy SO₄). **Nawias to pudełko na grupę** — bez niego indeks przykleiłby się tylko do ostatniego atomu. CaOH₂ sugeruje przypadkowy układ atomów, a nie dwie grupy OH.
:::

### Pięć rzeczy, których nie wolno mieszać {#piec-pojec}

| Pojęcie | Co opisuje | Przykład |
|---|---|---|
| **Wartościowość** | ile wiązań tworzy atom w danym związku | w CO₂: C — IV, O — II |
| **Stopień utlenienia** | umowny ładunek atomu przy całkowitym przesunięciu elektronów | w CO₂: C +IV, O −II |
| **Ładunek jonu** | rzeczywisty ładunek atomu lub grupy | Ca²⁺, Cl⁻, SO₄²⁻ |
| **Indeks dolny** | liczba atomów lub grup w jednej cząsteczce / jednostce wzoru | Ca(OH)₂: 1 Ca, 2 O, 2 H |
| **Współczynnik** | liczba cząsteczek albo jednostek wzoru w reakcji | 2H₂O: łącznie 4 H i 2 O |

W CaCl₂ wapń ma wartościowość II, a jon wapnia ładunek 2+ — wyniki podobne, rzeczy różne. W jonach mówimy o **wartościowości jonu** = wartość bezwzględna ładunku (Ca²⁺ → II), ale to nadal liczba wiązań, a nie nadmiar elektronów. W związkach jonowych nie wyodrębniamy pojedynczych wiązań — mówimy o **sieci jonowej**; wartościowość mówi, ile ładunków musi się zrównoważyć. **Indeks to część substancji, współczynnik to liczba porcji — dlatego bilansując, zmieniamy tylko współczynniki.**

### Wzory strukturalne i elektronowe [[understand:ROZUMIENIE]] {#strukturalne}

**Wzór strukturalny (kreskowy)** pokazuje, które atomy są połączone i ile wiązań tworzą: H–O–H, O=C=O, H–Cl. **Wzór elektronowy (kropkowy, Lewisa)** pokazuje elektrony walencyjne jako kropki: H:H, Cl:Cl, H:Cl. Te wzory pokazują, **skąd bierze się wartościowość** — widać, ile wiązań tworzy każdy atom.

| Związek | Sumaryczny | Strukturalny | Elektronowy |
|---|---|---|---|
| woda | H₂O | H–O–H | H:O:H (dwie wolne pary na O) |
| tlenek węgla(IV) | CO₂ | O=C=O | :O::C::O: |
| metan | CH₄ | C w środku, cztery wiązania C–H | H:C:H, z H nad i pod C |
| chlor | Cl₂ | Cl–Cl | :Cl:Cl: |
| chlorowodór | HCl | H–Cl (kowalencyjne spolaryzowane) | H:Cl: |

### Masa cząsteczkowa i masa jednostki wzoru {#masa}

**Masa cząsteczkowa** — suma mas atomowych wszystkich atomów we wzorze. Związki **kowalencyjne** tworzą odrębne cząsteczki (H₂O, CO₂, CH₄) — mówimy o masie cząsteczkowej. Związki **jonowe** tworzą sieć (NaCl, MgO, CaCl₂) — poprawniej mówimy o **masie jednostki wzoru**. W szkole często mówi się skrótowo „masa cząsteczkowa” także dla soli — pamiętaj o różnicy.

| Związek | Obliczenie | Wynik |
|---|---|---|
| H₂O | 2·1 + 16 | 18 u (masa cząsteczkowa) |
| CO₂ | 12 + 2·16 | 44 u (masa cząsteczkowa) |
| NaCl | 23 + 35,5 | 58,5 u (masa jednostki wzoru) |
| Ca(OH)₂ | 40 + 2·(16 + 1) | 74 u (masa jednostki wzoru) |
| H₂SO₄ | 2·1 + 32 + 4·16 | 98 u (masa cząsteczkowa) |

| Pojęcie | Co to jest | Przykład |
|---|---|---|
| Liczba masowa A | protony + neutrony (izotop) | ¹⁶O → A = 16 |
| Masa atomowa | średnia ważona izotopów | O → 16,00 u |
| Masa cząsteczkowa | suma mas atomowych (związki kowalencyjne) | H₂O → 18 u |
| Masa jednostki wzoru | suma mas atomowych (związki jonowe) | NaCl → 58,5 u |

## 6 | Wiązania chemiczne [[basic:E8]] {#wiazania}

W szkolnym modelu atomy tworzą wiązania, bo układ elektronów w związku jest energetycznie korzystniejszy; wiele atomów dąży do **oktetu**, wodór do **dubletu**. To model dydaktyczny, nie uniwersalne prawo: oktet dotyczy głównie grup głównych; wyjątki — H i He (dublet), Li, Be (często mniej niż oktet), P, S (mogą mieć powiększony oktet), metale przejściowe; reguła oktetu nie wyjaśnia wiązania metalicznego.

::: karta core | Algorytm rozpoznawania wiązania
1. Oba pierwiastki to metale → **metaliczne**.
2. Metal + niemetal → najczęściej **jonowe**.
3. Oba niemetale → **kowalencyjne**:
4. różne niemetale → zwykle **kowalencyjne spolaryzowane** (HCl, H₂O);
5. takie same niemetale → **kowalencyjne niespolaryzowane** (H₂, Cl₂, O₂).

**Metal oddaje, niemetal bierze; niemetale uwspólniają; metale tworzą morze elektronów.**
:::

| Cecha | Jonowe | Kowalencyjne | Metaliczne |
|---|---|---|---|
| Elektrony | przekazane; powstają jony | uwspólnione pary | zdelokalizowane („morze”) |
| Najczęściej między | metalem a niemetalem | niemetalami | metalami |
| Przykład | Na⁺Cl⁻, MgO, CaF₂ | H₂, HCl, H₂O, CO₂, CH₄ | Fe, Cu, Al, Na |
| Budowa substancji | uporządkowana sieć jonów | najczęściej cząsteczki; wyjątek: sieci kowalencyjne (diament, SiO₂) | sieć jonów dodatnich w morzu elektronów |
| Przewodzenie prądu | po stopieniu lub w roztworze | zwykle nie | tak (swobodne elektrony) |

::: regula
**Wiązanie jonowe** to przyciąganie elektrostatyczne między jonami o przeciwnych ładunkach w **sieci krystalicznej**; jony powstają zwykle przez przekazanie elektronów z metalu do niemetalu. Dlatego NaCl zapisujemy jako **wzór jednostki sieci jonowej**, a nie pojedynczą cząsteczkę — i dlatego przewodzi prąd dopiero po stopieniu lub rozpuszczeniu.
:::

**Wiązanie metaliczne:** dodatnie jony metalu zanurzone w „morzu elektronów”. Stąd przewodnictwo prądu i ciepła, kowalność i połysk metali.

::: karta extra | Elektroujemność i polaryzacja
**Elektroujemność** — miara zdolności atomu do przyciągania elektronów w wiązaniu; ogólnie rośnie w prawo i w górę, największa — **fluor**. To trend, nie automat: duża różnica elektroujemności **zwykle sprzyja** wiązaniu o silnym charakterze jonowym, mała — kowalencyjnemu; to wskazówka, nie test rozstrzygający. W klasie 7/8 najpierw stosuj prostszą regułę (metal + niemetal → jonowe; niemetale → kowalencyjne).
Polaryzacja: niespolaryzowane — takie same atomy (H₂, Cl₂); spolaryzowane — różne niemetale (HCl, H₂O): para elektronowa silniej przyciągana przez jeden atom.
:::

## 7 | Równania reakcji [[basic:E8]] {#rownania}

::: regula
**Prawo zachowania masy:** w reakcji atomy nie znikają i nie powstają z niczego — tylko łączą się inaczej. Liczba atomów każdego pierwiastka przed strzałką i po strzałce musi być taka sama; **masa substratów = masa produktów**.
:::

::: karta core | Procedura bilansowania
1. Zapisz poprawne wzory substratów i produktów.
2. Policz atomy każdego pierwiastka po obu stronach.
3. Zacznij od pierwiastka występującego w najmniejszej liczbie wzorów.
4. Ustaw współczynniki przed wzorami.
5. Wodór i tlen zwykle na koniec.
6. Sprawdź wszystkie pierwiastki; skróć współczynniki do najmniejszych liczb całkowitych.
7. **Nigdy nie zmieniaj indeksów dolnych.** — „Współczynniki tak, indeksy nie!”
:::

**Współczynnik mnoży wszystko:** 2H₂O to 4 atomy H i 2 atomy O; 3Ca(OH)₂ to 3 Ca, 6 O i 6 H.

| Zapis | Co oznacza | Co obejmuje |
|---|---|---|
| H₂O | indeks dolny 2 | dwa atomy H w jednej cząsteczce wody |
| 3H₂O | współczynnik 3 | trzy cząsteczki H₂O: 6 H i 3 O |
| Ca(OH)₂ | nawias i indeks 2 | dwie całe grupy OH |

Substraty — po lewej, produkty — po prawej. Strzałka nie znaczy „równa się”, tylko „reaguje, tworząc”. **Kontrprzykład:** H₂ + O₂ → H₂O₂ to inna substancja (nadtlenek wodoru); poprawnie: 2H₂ + O₂ → 2H₂O.

### Bilansowanie krok po kroku {#bilans}

| Równanie | Kroki | Wynik |
|---|---|---|
| Fe + O₂ → Fe₂O₃ | Fe: 1 vs 2, O: 2 vs 3 → 4Fe i 2Fe₂O₃ → tlen: 6 → 3O₂ | **4Fe + 3O₂ → 2Fe₂O₃** |
| Al + HCl → AlCl₃ + H₂ | 2Al → 2AlCl₃ → Cl: 6 → 6HCl → H: 6 → 3H₂ | **2Al + 6HCl → 2AlCl₃ + 3H₂** |
| C₂H₆ + O₂ → CO₂ + H₂O | C: 2CO₂; H: 3H₂O; O: 4 + 3 = 7 → 7/2 O₂; całość × 2 | **2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O** |

### Typy reakcji {#typy}

| Typ | Schemat | Przykład |
|---|---|---|
| Synteza | A + B → AB | 2Mg + O₂ → 2MgO |
| Analiza (rozkład) | AB → A + B | CaCO₃ → CaO + CO₂ |
| Wypieranie (wymiana pojedyncza) | A + BC → AC + B | Zn + CuSO₄ → ZnSO₄ + Cu; Zn + 2HCl → ZnCl₂ + H₂ |
| Podwójna wymiana | AB + CD → AD + CB | AgNO₃ + NaCl → AgCl↓ + NaNO₃ (↓ — osad) |
| Spalanie | substancja + O₂ → tlenki + energia | CH₄ + 2O₂ → CO₂ + 2H₂O |

Skrót: **S A W P S** — synteza, analiza, wypieranie, podwójna wymiana, spalanie.

::: karta warning | Spalanie — uwaga
Spalanie to szybka reakcja substancji z tlenem, której zwykle towarzyszy wydzielanie energii (ciepło, światło). Obecność O₂ po lewej stronie **nie wystarcza**, żeby bez zastanowienia nazwać reakcję spalaniem — analizuj, co reaguje i co powstaje.
:::

| Typ | Ciepło | Przykład |
|---|---|---|
| Egzotermiczna | wydziela (exo — „na zewnątrz”) | spalanie CH₄, reakcja metalu z kwasem |
| Endotermiczna | pochłania (endo — „do wewnątrz”) | rozkład CaCO₃ (wymaga ogrzewania) |

**Warunki nad strzałką:** 2KClO₃ —(Δ, MnO₂)→ 2KCl + 3O₂ — Δ oznacza ogrzewanie; MnO₂ to katalizator: przyspiesza reakcję, ale się nie zużywa.

::: karta warning | BHP do przykładów
2K + 2H₂O → 2KOH + H₂ — potas reaguje z wodą bardzo gwałtownie. To przykład do analizy równania, nie doświadczenie do samodzielnego wykonania.
:::

::: karta extra | Rozpuszczalność i zapis jonowy (przygotowanie do klasy 8)
**Uproszczona tabela rozpuszczalności:** azotany(V) — rozpuszczalne; sole metali alkalicznych (Li, Na, K, Rb, Cs) — rozpuszczalne; chlorki — rozpuszczalne, wyjątki: AgCl, PbCl₂, Hg₂Cl₂; siarczany — rozpuszczalne, wyjątki: BaSO₄, PbSO₄, CaSO₄ (słabo); węglany — nierozpuszczalne, wyjątki: sole metali alkalicznych i NH₄⁺; wodorotlenki — nierozpuszczalne, wyjątki: NaOH, KOH, Ba(OH)₂, Ca(OH)₂ (słabo).
**Zapis jonowy** pokazuje jony rzeczywiście reagujące: AgNO₃ + NaCl → AgCl↓ + NaNO₃ → **Ag⁺ + Cl⁻ → AgCl↓**; Na⁺ i NO₃⁻ się nie zmieniają — to **jony widzowie**.
:::

## 8 | Jak wybrać strategię? [[understand:ROZUMIENIE]] {#strategia}

| Masz… | Kroki |
|---|---|
| atom lub jon | odczytaj Z → protony; atom: e⁻ = Z; jon: odejmij/dodaj elektrony wg ładunku; n⁰ = A − Z |
| ułożyć wzór | symbole lub grupa → wartościowości albo ładunki → W–K–S–K → sprawdź nawias i indeks 1 |
| zbilansować równanie | nie zmieniaj indeksów → policz atomy → ustaw współczynniki → sprawdź wszystkie pierwiastki |
| narysować wzór strukturalny | wartościowość każdego atomu → połącz kreskami → sprawdź liczbę wiązań; dla elektronowego zamień kreski na pary kropek |

## 9 | Pułapki i STOP przed oddaniem {#pulapki}

| Błąd | Dlaczego to błąd | Jak poprawić |
|---|---|---|
| zmiana indeksów przy bilansowaniu | indeks należy do wzoru | zmieniamy tylko współczynniki |
| FeO₃ zamiast Fe₂O₃ | brak krzyżowania / kontroli | Feᴵᴵᴵ + Oᴵᴵ → Fe₂O₃; 2·3 = 3·2 |
| brak wartościowości Fe/Cu w nazwie | zmienna wartościowość | tlenek żelaza(III), chlorek miedzi(II) |
| mylenie Z z A | różne pojęcia | Z = p⁺; A = p⁺ + n⁰ |
| mylenie A z masą atomową | A — izotop (całkowita); masa atomowa — średnia | patrz [§2](#atom) |
| brak nawiasu przy grupie | indeks dotyczyłby tylko ostatniego atomu | Ca(OH)₂, nie CaOH₂ |
| „wartościowość zawsze = nr grupy” | grupy 15–17 mają warianty | sprawdzaj kontekst |
| „wymiana” bez rozróżnienia | wypieranie ≠ podwójna wymiana | nazywaj precyzyjnie |
| „jest O₂ → to spalanie” | nie zawsze wystarcza | analizuj substraty i produkty |
| wartościowość = ładunek jonu | różne pojęcia | patrz [§5](#piec-pojec) |
| masa atomowa = cząsteczkowa | jeden atom vs cała cząsteczka | patrz [§5](#masa) |

::: checklista
- Czy odróżniam Z od A?
- Czy w atomie obojętnym liczba protonów = liczba elektronów?
- Czy wzór jest w najprostszym stosunku atomów?
- Czy użyłem nawiasu przy powtarzającej się grupie?
- Czy bilansując, zmieniałem tylko współczynniki?
- Czy po obu stronach równania liczba atomów każdego pierwiastka jest taka sama?
:::

## 10 | Klinika błędów {#klinika}

**Zasada:** błąd → znajdź → popraw → nazwij regułę → wyjaśnij dlaczego.

::: klinika | Błąd | Poprawnie | Dlaczego?
| CaOH₂ | Ca(OH)₂ | Reguła: nawias obejmuje całą grupę. Indeks 2 dotyczy całego OH, nie tylko H. |
| FeO₃ | Fe₂O₃ | Reguła: krzyżowanie + kontrola. Fe(III), O(II) → 2·3 = 3·2. |
| H₂ + O₂ → H₂O₂ | 2H₂ + O₂ → 2H₂O | Reguła: nie zmieniaj indeksów. H₂O₂ to nadtlenek wodoru — inna substancja. |
| Al + HCl → AlCl₃ + H₂ | 2Al + 6HCl → 2AlCl₃ + 3H₂ | Reguła: bilansuj współczynnikami. Liczba atomów musi się zgadzać. |
| Na⁺ ma 11 elektronów | Na⁺ ma 10 elektronów | Reguła: kation oddał elektron. 11 − 1 = 10. |
| Cl ma 17 neutronów | ³⁵Cl ma 18 neutronów | Reguła: n⁰ = A − Z. 35 − 17 = 18. |
| „Tlenek żelaza” | „Tlenek żelaza(III)” | Reguła: Fe ma II/III — nazwa musi precyzować wartościowość. |
| „Wartościowość = numer grupy” | zależy od grupy | Reguła: grupy 15–17 mają warianty, np. S: II, IV, VI. |
| „Jest O₂ → to spalanie” | analizuj substraty i produkty | Reguła: spalanie = reakcja z O₂ + wydzielanie energii; nie każda reakcja z O₂ nią jest. |
| Mg + O₂ → MgO | 2Mg + O₂ → 2MgO | Reguła: bilansuj. Po obu stronach tyle samo atomów. |
| „Wartościowość = ładunek jonu” | pokrewne, ale różne | Reguła: wartościowość = liczba wiązań; ładunek = nadmiar/niedobór e⁻. |
| H₂O ma masę 18 g | masa cząsteczkowa H₂O = 18 u | Reguła: u to jednostka masy atomowej, nie gram (1 u ≈ 1,66·10⁻²⁴ g). |
:::

::: karta understand | Ćwiczenie kliniki — znajdź i popraw błąd
1. CaOH₂ 2. FeO₃ 3. H₂ + O₂ → H₂O₂ 4. Na⁺ ma 11 elektronów 5. „Tlenek żelaza” 6. Mg + O₂ → MgO 7. Al + HCl → AlCl₃ + H₂ 8. „Wartościowość siarki = 6, bo jest w grupie 16” 9. „Jest O₂ → to spalanie” 10. „Wartościowość = ładunek jonu” 11. „Masa cząsteczkowa H₂O to 18 g” 12. „Wiązanie metaliczne to to samo co jonowe”

::: odp | Pokaż odpowiedzi
1. Ca(OH)₂ — nawias. 2. Fe₂O₃ — krzyżowanie. 3. 2H₂ + O₂ → 2H₂O — nie zmieniaj indeksów. 4. 10 elektronów — kation oddał. 5. Tlenek żelaza(III) — Fe ma II/III. 6. 2Mg + O₂ → 2MgO. 7. 2Al + 6HCl → 2AlCl₃ + 3H₂. 8. S ma II, IV lub VI — nie zawsze numer grupy. 9. Analizuj substraty i produkty. 10. To pokrewne, ale różne pojęcia. 11. 18 u, nie gramów. 12. Metaliczne — morze elektronów; jonowe — przekazanie elektronów i sieć jonów.
:::

## 11 | Ćwiczenia {#cwiczenia}

### A. Diagnostyka fundamentów (5 minut) {#cw-a}

1. Wybierz poprawny zapis: CaOH₂ czy Ca(OH)₂? Wyjaśnij jednym zdaniem.
2. Wybierz poprawne równanie otrzymywania wody: H₂ + O₂ → H₂O₂ czy 2H₂ + O₂ → 2H₂O?
3. Jon Al³⁺ ma 13 protonów. Ile ma elektronów?
4. Czy Ca₂O₂ jest wzorem błędnym? Dlaczego zapisujemy CaO?

### 12.3 Doświadczenia: obserwacja → wniosek → równanie {#doswiadczenia}

::: nie-myl
**Obserwacja** — to, co widzisz, czujesz, mierzysz (barwa, osad, gaz, zmętnienie, ciepło). **Wniosek** — co z tego wynika (jaka substancja powstała, jaka reakcja zaszła). „Wydziela się wodór” to wniosek; „wydzielają się pęcherzyki bezbarwnego gazu” — obserwacja.
:::

::: dosw | Doświadczenie 1 — Wykrywanie tlenku węgla(IV) wodą wapienną
Problem: Jak wykazać, że w wydychanym powietrzu (albo w produktach spalania) jest tlenek węgla(IV)?
Hipoteza: Tlenek węgla(IV) powoduje zmętnienie wody wapiennej.
Sprzęt: probówka z klarowną wodą wapienną (nasycony roztwór Ca(OH)₂), rurka szklana lub słomka.
Przebieg: Przez rurkę wdmuchujemy powietrze z płuc do wody wapiennej.
Obserwacja: Klarowna woda wapienna mętnieje — powstaje biały osad.
Wniosek: W wydychanym powietrzu jest CO₂; z wodą wapienną tworzy trudno rozpuszczalny węglan wapnia.
Równanie:: Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
BHP: nie zasysamy cieczy przez rurkę; woda wapienna jest zasadowa — okulary ochronne.
:::

::: dosw | Doświadczenie 2 — Redukcja tlenku miedzi(II) węglem (pokaz nauczyciela)
Problem: Czy węgiel może odebrać tlen tlenkowi metalu?
Hipoteza: Ogrzewana mieszanina CuO i węgla daje miedź i tlenek węgla(IV).
Sprzęt: probówka z mieszaniną czarnego tlenku miedzi(II) i sproszkowanego węgla, rurka odprowadzająca do probówki z wodą wapienną, palnik, statyw.
Przebieg: Mieszaninę ogrzewamy silnie; powstający gaz wprowadzamy do wody wapiennej.
Obserwacja: Czarna mieszanina zmienia barwę — pojawiają się czerwonobrunatne drobiny; woda wapienna mętnieje.
Wniosek: Powstała miedź i tlenek węgla(IV); węgiel odebrał tlen tlenkowi miedzi(II) (jest reduktorem).
Równanie:: 2CuO + C → 2Cu + CO₂↑
BHP: pokaz nauczyciela; po zakończeniu ogrzewania najpierw wyjmujemy rurkę z wody wapiennej, dopiero potem gasimy palnik (zapobiega cofnięciu się cieczy do gorącej probówki).
:::

## 13 | Rozszerzenie i dla ambitnych [[extra:AMBITNE]] {#ambitne}

::: karta extra | Powłoki i podpowłoki
**Dla pierwszych 20 pierwiastków** — zapis powłokowy **2, 8, 8, 2**: K mieści maks. 2 elektrony, L — 8, M może mieścić do 18, ale w atomach pierwszych 20 pierwiastków po 8 elektronach na M zaczyna się zapełniać N.
**Podpowłoki (ambitnie):** kolejność zapełniania 1s → 2s → 2p → 3s → 3p → 4s, dalej 3d → 4p → 5s… s — 1 orbital (2 e⁻), p — 3 (6 e⁻), d — 5 (10 e⁻), f — 7 (14 e⁻).
:::

::: karta extra | Alotropia, izobary i inne
- **Alotropia** — ten sam pierwiastek w różnych postaciach o różnej budowie i właściwościach: O₂ i O₃; diament, grafit, fullereny; fosfor biały, czerwony, czarny.
- **Izobary** — ten sam A, różny Z (izotopy: ten sam Z, różny A).
- **P₄O₁₀ vs P₂O₅** — rzeczywista cząsteczka vs najprostszy stosunek atomów.
- **Sieci kowalencyjne** (diament, SiO₂) — wyjątek od „związki kowalencyjne tworzą cząsteczki”.
- **Spalanie niecałkowite** — przy niedoborze tlenu mogą powstać CO i C.
- Wyjątki od reguły oktetu/dubletu; nietrwały SO; wartościowość a stopień utlenienia.
:::

## 17 | Słownik {#slownik}

::: slownik
Atom :: elektrycznie obojętna cząstka pierwiastka złożona z jądra i elektronów
Jon :: atom lub grupa atomów mająca ładunek, bo oddała albo przyjęła elektrony
Kation :: jon o ładunku dodatnim (oddał elektrony)
Anion :: jon o ładunku ujemnym (przyjął elektrony)
Izotopy :: atomy tego samego pierwiastka: tyle samo protonów, różna liczba neutronów
Liczba atomowa Z :: liczba protonów; określa, jaki to pierwiastek
Liczba masowa A :: suma protonów i neutronów w konkretnym izotopie
Masa atomowa :: średnia ważona mas izotopów pierwiastka (liczba dziesiętna z układu okresowego)
Elektrony walencyjne :: elektrony najbardziej zewnętrznej zajętej powłoki, biorące udział w tworzeniu wiązań
Wartościowość :: szkolna informacja, ile wiązań tworzy atom w danym związku
Indeks dolny :: liczba atomów danego pierwiastka lub grupy w jednym wzorze
Współczynnik :: liczba całych cząsteczek albo jednostek wzoru w równaniu
Substraty :: substancje, które reagują (po lewej stronie strzałki)
Produkty :: substancje powstające w reakcji (po prawej stronie strzałki)
Wiązanie jonowe :: przyciąganie elektrostatyczne jonów o przeciwnych ładunkach w sieci krystalicznej
Wiązanie kowalencyjne :: wiązanie przez uwspólnienie par elektronowych między atomami niemetali
Wiązanie metaliczne :: dodatnie jony metalu w „morzu” zdelokalizowanych elektronów
Elektroujemność :: zdolność atomu do przyciągania elektronów w wiązaniu
Masa cząsteczkowa :: suma mas atomowych wszystkich atomów w cząsteczce
Alotropia :: występowanie pierwiastka w różnych postaciach o różnej budowie i właściwościach
:::

## 19 | Co dalej? {#dalej}
