1 Budowa i definicja soli
Definicja

Sól — związek chemiczny zbudowany z kationów metalu (lub kationu amonu NH₄⁺) i anionów reszty kwasowej.

MnRm (n · ładunek kationu = m · |ładunek anionu|)

W stanie stałym sól tworzy kryształ jonowy: jony ułożone regularnie, przyciągane siłami elektrostatycznymi. Stąd wysokie temperatury topnienia (NaCl — 801 °C), kruchość i przewodzenie prądu w stopie i w roztworze.

Skąd biorą się sole?

Sól powstaje, gdy H z kwasu zostaje „zastąpiony” metalem: HCl → NaCl, H₂SO₄ → Na₂SO₄ (sól obojętna) lub NaHSO₄ (sól wodorowa — zastąpiono tylko część H). Z drugiej strony grupy OH z wodorotlenku zastępuje reszta kwasowa.

2 Wzory i nazwy soli
Reguła wzoru — krzyżowanie ładunków
  1. Zapisz jony z ładunkami: Fe³⁺ i SO₄²⁻.
  2. „Skrzyżuj” wartości ładunków jako indeksy: Fe₂(SO₄)₃.
  3. Skróć, jeśli się da (Ca²⁺ + CO₃²⁻ → CaCO₃, nie Ca₂(CO₃)₂).
  4. Sprawdź: 2·(+3) + 3·(−2) = 0 ✓. Jon wieloatomowy w nawiasie, gdy jest go więcej niż jeden.

Wartościowość metalu w nazwie

Dla metali o zmiennej wartościowości podajemy ją cyfrą rzymską: FeCl₂ — chlorek żelaza(II), FeCl₃ — chlorek żelaza(III), CuSO₄ — siarczan(VI) miedzi(II). Dla Na, K, Mg, Ca, Ba, Al, Zn, Ag — nie podajemy.

LO — sole wodorowe, hydroksosole, hydraty
  • Wodorosole: NaHCO₃ — wodorowęglan sodu, NaHSO₄ — wodorosiarczan(VI) sodu, NaH₂PO₄ — diwodorofosforan(V) sodu.
  • Hydroksosole: Mg(OH)Cl — chlorek wodorotlenek magnezu.
  • Hydraty: CuSO₄·5H₂O — siarczan(VI) miedzi(II)—woda(1/5), CaSO₄·2H₂O — gips.
3 Dysocjacja soli i tabela rozpuszczalności
Dysocjacja (sole rozpuszczalne)
NaCl → Na⁺ + Cl⁻
K₂SO₄ → 2 K⁺ + SO₄²⁻
Al₂(SO₄)₃ → 2 Al³⁺ + 3 SO₄²⁻
Ca(NO₃)₂ → Ca²⁺ + 2 NO₃⁻

Sole są mocnymi elektrolitami: to, co się rozpuściło, jest całkowicie zdysocjowane. Sól nierozpuszczalna (np. CaCO₃) praktycznie nie daje jonów w roztworze.

Jak czytać tabelę rozpuszczalności
  • R — rozpuszczalny (> 1 g w 100 g wody) · T — trudno rozpuszczalny (0,1–1 g) · N — nierozpuszczalny (< 0,1 g) · — — nie istnieje w wodzie / rozkłada się.
  • Zawsze rozpuszczalne: sole sodu, potasu, amonu i wszystkie azotany(V).
  • Chlorki — rozpuszczalne poza AgCl (N) i PbCl₂ (T). Siarczany(VI) — poza BaSO₄, PbSO₄ (N) oraz CaSO₄, Ag₂SO₄ (T).
  • Węglany, fosforany(V), siarczki — w większości nierozpuszczalne (poza Na, K, NH₄).
4 Otrzymywanie soli — 10 metod
Mnemonik: 10 dróg do soli

Zapamiętaj pary substratów: M+K · TM+K · W+K · M+N · TM+TN · W+TN · S+K · S+Z · S+S · M+S (M — metal, K — kwas, TM / TN — tlenek metalu / niemetalu, W — wodorotlenek, N — niemetal, S — sól, Z — zasada).

1. Metal + kwas → sól + wodór

Zn + 2 HCl → ZnCl₂ + H₂↑
Mg + H₂SO₄ → MgSO₄ + H₂↑

Tylko metale przed wodorem w szeregu aktywności.

2. Tlenek metalu + kwas → sól + woda

CuO + H₂SO₄ → CuSO₄ + H₂O
CaO + 2 HCl → CaCl₂ + H₂O

3. Wodorotlenek + kwas → sól + woda (zobojętnianie)

HCl + NaOH → NaCl + H₂O
2 H₃PO₄ + 3 Ca(OH)₂ → Ca₃(PO₄)₂ + 6 H₂O

4. Metal + niemetal → sól kwasu beztlenowego

2 Na + Cl₂ → 2 NaCl
Fe + S → FeS

5. Tlenek metalu + tlenek niemetalu → sól kwasu tlenowego

CaO + CO₂ → CaCO₃

6. Wodorotlenek + tlenek niemetalu → sól + woda

2 NaOH + CO₂ → Na₂CO₃ + H₂O
Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O

Druga reakcja to wykrywanie CO₂ wodą wapienną.

7. Sól + kwas → nowa sól + nowy kwas

CaCO₃ + 2 HCl → CaCl₂ + H₂O + CO₂↑
AgNO₃ + HCl → AgCl↓ + HNO₃

Zachodzi, gdy powstaje gaz, osad lub słabszy kwas.

8. Sól + zasada → nowa sól + nowy wodorotlenek

CuSO₄ + 2 NaOH → Cu(OH)₂↓ + Na₂SO₄
FeCl₃ + 3 NaOH → Fe(OH)₃↓ + 3 NaCl

Zachodzi, gdy powstaje osad wodorotlenku.

9. Sól + sól → dwie nowe sole

AgNO₃ + NaCl → AgCl↓ + NaNO₃
BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2 NaCl
Pb(NO₃)₂ + 2 KI → PbI₂↓ + 2 KNO₃

Obie sole muszą być rozpuszczalne, a jeden produkt — nie.

10. Metal + sól → nowa sól + nowy metal (wypieranie)

Zn + CuSO₄ → ZnSO₄ + Cu
Fe + CuSO₄ → FeSO₄ + Cu
Cu + 2 AgNO₃ → Cu(NO₃)₂ + 2 Ag

Metal aktywniejszy (wcześniej w szeregu) wypiera mniej aktywny. Cu + ZnSO₄ — brak reakcji.

5 Reakcje strąceniowe i wykrywanie jonów
Reguła

Mieszamy dwa roztwory soli (lub sól i zasadę/kwas). Jeśli z jonów obecnych w roztworze może powstać związek oznaczony w tabeli jako N (lub T) — wytrąca się osad. Jony, które się nie zmieniają, to jony obserwatory.

Trzy poziomy zapisu — AgNO₃ + NaCl
AgNO₃ + NaCl → AgCl↓ + NaNO₃
Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl↓ + Na⁺ + NO₃⁻
Ag⁺ + Cl⁻ → AgCl↓

Na⁺ i NO₃⁻ — jony obserwatory.

6 Wypieranie metali — szereg aktywności
Reguła

Metal stojący w szeregu aktywności wcześniej (aktywniejszy) wypiera z roztworu soli metal stojący dalej:

K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Ag > Au

Fe + CuSO₄ → FeSO₄ + Cu
jonowo: Fe + Cu²⁺ → Fe²⁺ + Cu

To reakcja redoks: Fe oddaje elektrony (utlenia się), Cu²⁺ je przyjmuje (redukuje się).

Cu + FeSO₄ — brak reakcji (Cu stoi za Fe). Metale K, Ca, Na reagują najpierw z wodą — do wypierania się nie nadają.

8 Odczyn roztworów soli — hydroliza LO
Kiedy roztwór soli nie jest obojętny?

Jon pochodzący od słabego kwasu lub słabej zasady reaguje z wodą (hydroliza):

SólPochodzi odOdczynRównanie hydrolizy
NaCl, K₂SO₄mocny kwas + mocna zasadaobojętnybrak hydrolizy
Na₂CO₃słaby kwas + mocna zasadazasadowyCO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻
CH₃COONasłaby kwas + mocna zasadazasadowyCH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻
NH₄Clmocny kwas + słaba zasadakwasowyNH₄⁺ + H₂O ⇌ NH₃ + H₃O⁺
CuSO₄mocny kwas + słaba zasadakwasowyCu²⁺ + 2 H₂O ⇌ CuOH⁺ + H₃O⁺

Dlatego roztwór sody barwi fenoloftaleinę na malinowo, a roztwór CuSO₄ czerwieni papierek uniwersalny.

Hydroliza ilościowo poziom akademicki · poza maturą rozszerzoną

Dla anionu słabego kwasu: Kb = Kw/Ka. Np. CH₃COO⁻: Kb = 10⁻¹⁴ / 1,75·10⁻⁵ ≈ 5,7·10⁻¹⁰; dla 0,1 mol/dm³ CH₃COONa [OH⁻] ≈ √(Kb·c) ≈ 7,6·10⁻⁶ → pOH ≈ 5,1, pH ≈ 8,9. Dla CO₃²⁻ (Ka2 H₂CO₃ = 4,68·10⁻¹¹) Kb ≈ 2,1·10⁻⁴ → 0,1 M Na₂CO₃ ma pH ≈ 11,7. Kationy metali hydrolizują jako akwakompleksy: [Fe(H₂O)₆]³⁺ ⇌ [Fe(OH)(H₂O)₅]²⁺ + H⁺ (pKa ≈ 2,2).

9 Sole w przyrodzie i w organizmie BIOL-CHEM
Biologia i medycyna
  • Na⁺ i K⁺ — potencjał spoczynkowy błony komórkowej (pompa sodowo-potasowa); nadmiar NaCl w diecie podnosi ciśnienie krwi.
  • Ca²⁺ i fosforany — kości i zęby (hydroksyapatyt Ca₁₀(PO₄)₆(OH)₂), krzepnięcie krwi, skurcz mięśni.
  • Kamienie nerkowe — najczęściej szczawian wapnia CaC₂O₄ (N).
  • Sól fizjologiczna — 0,9% NaCl, izotoniczna z osoczem.
  • BaSO₄ jest kontrastem RTG, bo jest nierozpuszczalny — rozpuszczalne sole baru są trujące.
  • Fosforany w ATP i DNA; nadmiar fosforanów i azotanów z nawozów → eutrofizacja wód.

12 Ćwiczenia

Poziom A — podstawa

  1. Napisz wzory: chlorek magnezu, siarczan(VI) glinu, azotan(V) wapnia, fosforan(V) sodu.
  2. Nazwij: K₂CO₃, FeCl₂, Fe₂(SO₄)₃, CuS.
  3. Zapisz dysocjację: Na₂SO₄, Al(NO₃)₃, K₃PO₄.
  4. Odczytaj z tabeli: czy rozpuszczalne są AgCl, Na₂CO₃, BaSO₄, CaCO₃?
Pokaż odpowiedzi
  1. MgCl₂, Al₂(SO₄)₃, Ca(NO₃)₂, Na₃PO₄.
  2. węglan potasu, chlorek żelaza(II), siarczan(VI) żelaza(III), siarczek miedzi(II).
  3. Na₂SO₄ → 2 Na⁺ + SO₄²⁻; Al(NO₃)₃ → Al³⁺ + 3 NO₃⁻; K₃PO₄ → 3 K⁺ + PO₄³⁻.
  4. AgCl — N, Na₂CO₃ — R, BaSO₄ — N, CaCO₃ — N.

Poziom B — trening

  1. Zaproponuj 3 sposoby otrzymania MgCl₂ — zapisz równania.
  2. Uzupełnij: Zn + CuSO₄ → ? ; Cu + AgNO₃ → ? ; Cu + FeSO₄ → ?
  3. Zapisz cząsteczkowo i jonowo (skrócono): BaCl₂ + K₂SO₄.
  4. Które pary roztworów dadzą osad: (a) NaCl + AgNO₃, (b) KNO₃ + NaCl, (c) CuCl₂ + NaOH?
Pokaż odpowiedzi
  1. Mg + 2 HCl → MgCl₂ + H₂↑; MgO + 2 HCl → MgCl₂ + H₂O; Mg(OH)₂ + 2 HCl → MgCl₂ + 2 H₂O (lub Mg + Cl₂ → MgCl₂).
  2. ZnSO₄ + Cu; Cu(NO₃)₂ + 2 Ag; brak reakcji.
  3. BaCl₂ + K₂SO₄ → BaSO₄↓ + 2 KCl; Ba²⁺ + SO₄²⁻ → BaSO₄↓.
  4. (a) tak — AgCl; (b) nie; (c) tak — Cu(OH)₂.

Poziom C — ambitny

  1. Jak rozróżnić roztwory NaCl, Na₂SO₄ i Na₂CO₃, mając HCl, BaCl₂ i AgNO₃? Zaplanuj kolejność.
  2. Oblicz masę osadu AgCl, który powstanie z 5,85 g NaCl (nadmiar AgNO₃).
  3. Wyjaśnij, dlaczego woda twarda daje kamień kotłowy. Zapisz równanie.
Pokaż odpowiedzi
  1. HCl: musuje tylko Na₂CO₃. Do pozostałych BaCl₂: biały osad — Na₂SO₄. Ostatni z AgNO₃ — biały osad AgCl — NaCl.
  2. n(NaCl) = 5,85 / 58,44 ≈ 0,1 mol → n(AgCl) = 0,1 mol → m = 0,1 · 143,32 ≈ 14,3 g.
  3. Ca(HCO₃)₂ → CaCO₃ + H₂O + CO₂ — przy ogrzewaniu wytrąca się nierozpuszczalny CaCO₃.

Poziom D — LO rozszerzone

  1. Przewidź odczyn: K₂CO₃, NH₄NO₃, KCl, CH₃COOK. Zapisz równania hydrolizy.
  2. Dlaczego w zapisie jonowym CaCO₃ + 2 HCl CaCO₃ zostaje w postaci cząsteczkowej?
Pokaż odpowiedzi
  1. K₂CO₃ — zasadowy (CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻); NH₄NO₃ — kwasowy (NH₄⁺ + H₂O ⇌ NH₃ + H₃O⁺); KCl — obojętny; CH₃COOK — zasadowy.
  2. CaCO₃ jest nierozpuszczalny (N) — w roztworze nie występuje jako jony: CaCO₃ + 2 H⁺ → Ca²⁺ + H₂O + CO₂↑.
Iloczyn rozpuszczalności i efekt wspólnego jonu poziom akademicki · poza maturą rozszerzoną

Dla osadu MₐXᵦ: Ksp = [M]ᵃ[X]ᵇ (np. AgCl: Ksp = 1,77·10⁻¹⁰ → rozpuszczalność s = √Ksp ≈ 1,33·10⁻⁵ mol/dm³). Osad wytrąca się, gdy iloczyn stężeń jonów przekroczy Ksp. Dodatek wspólnego jonu (np. NaCl do roztworu nad AgCl) zmniejsza rozpuszczalność; z kolei tworzenie kompleksów zwiększa ją (AgCl rozpuszcza się w NH₃: AgCl + 2 NH₃ → [Ag(NH₃)₂]⁺ + Cl⁻).
