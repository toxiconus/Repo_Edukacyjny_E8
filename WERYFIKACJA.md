# WERYFIKACJA LEKCJI — rejestr

**W1 = weryfikacja zapisu:** zewnętrzny model (Perplexity) sprawdził **treść wysłanego pliku** — błędy, nieścisłości, uproszczenia, brakujące doprecyzowania i zadania z kluczem. **Nie** sprawdzał zakresu (zgodności z podstawą programową / wymaganiami konkursu).
**W2 = weryfikacja zakresu:** porównanie lekcji z podstawą programową, informatorem CKE i zakresem LKO — osobny krok, jeszcze nie wykonany.
